# 014-战斗视觉与镜头契约

本批实现三炮塔/三底盘真实3D细节、斜视近景跟随镜头、训练地面/掩体装饰与紧凑中文HUD。以现有白瓷/金色/深色资源作为造型参考，不使用PNG代替战斗模型。

- 六个部件仍由TankPartCatalog装配，TurretSocket=(0,0.76,0)、Muzzle=(0,0.02,-1.05)，根变换与挂点方向不变，无视觉碰撞。
- 通过可重建工具生成独立网格场景，共享材质与重复网格；静态原assets只读。白色装甲、深色橡胶、金色轮毂/炮口和绿色观察镜为统一方向，模型为本项目独立风格化制作，不声称等同设定图精度。
- ArenaDressing仅提供无碰撞装饰。原地板、墙与四掩体的碰撞坐标尺寸不变；新增装饰不得暗示不存在的可碰撞物。
- 镜头只跟随已提交的位置，不改角色；指数平滑、死区、有限焦点边界。暂停停止跟随，复活远距移动切镜头而非长距离拖动。输入仍使用CameraRig水平基/地平面投影。
- HUD只消费已提交事件及解析属性，沿用当前输入、暂停、训练/对局路由。新文案集中管理。
- 验收：保留全部旧测试；补镜头投影往返、不同步长平滑一致、边界与暂停检查；实际渲染九种装配、训练及对练截图。桌面截图不替代Android或性能验收。
