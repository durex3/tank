# 059 泡泡炮美术来源与接入

## 素材来源与技术规格

内置image_gen生成两张独立透明图：assets/generated/vfx/bubble-v2/bubble-source.png、pop-source.png。原图保留，提示词原文见同目录prompts.txt，生成与规格见provenance.json。工具输出由用户授权用于本项目；不编造第三方许可。

tools/prepare_bubble_art.gd按Lanczos归一为bubble.png与pop.png，均512×512 RGBA，保持真实alpha、居中锚点、mipmap/线性采样。泡体中心透明度由自动回归验证，额外轻薄球面膜由Shader补足体积；生成PNG仅作特效纹理。

## 真实装配模型

tools/build_bubble_refined.gd复用既有倒角、空心管和网格打包工具，原创新增presentation/parts/bubble_refined/bubble_cannon.tscn，旧模型与原卡片保留。模型采用圆形分片装甲、黑色机械内层、空心金色喷口、连续波纹软管、半罐液体、玻璃反光、双光学传感器及罐盖螺栓。静态不透明部件按材质合并，透明玻璃和液体独立。

卡片仍为turrets-atlas-v1.png中的原泡泡炮；本次没有以整车生图替代部件装配。炮口Marker及挂点不变，模型无CollisionObject或CollisionShape。

## 动态表现接口和预算

BubbleVisual消费已提交弹丸，按tick进行6tick展开、0.045米轻微浮动和最后18tick收缩；生成膜与浅透明球面仅作显示，不改0.25/0.45米权威半径。阵营继续圆/四角底环区分，底环alpha0.25。

BubbleBursts只消费weapon_fired/projectile_hit；枪口8tick、破裂14tick、瞬态上限24。暂停后无提交tick，不漂浮、不淡出；结束清瞬态，退出随会话销毁。双泡同tick提示合并显示最高命中计数，避免1/2与2/2文字叠在一起。

两张运行纹理含完整mipmap约2.7MiB RGBA估算，尚非Android实测。泡体受现有128弹丸预算约束，单普通弹为薄膜/膜体/尾泡3个表现，单留场泡为薄膜/膜体/底环3个表现；重叠透明过绘制和低端真机性能待验。
