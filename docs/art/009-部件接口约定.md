# 009部件接口约定

先约定接口再实现。TankView.configure_parts(weapon_id, chassis_id)返回空字符串表示成功，错误时保留原装配。部件目录由TankPartCatalog持有，领域定义不引用PackedScene。三个底盘与三个炮塔各独立一个可编辑tscn，属于表现层，无脚本/碰撞/战斗数据。

底盘根在地面中心，直接子Marker3D TurretSocket位于(0,0.76,0)，XZ必须为零。炮塔根是旋转轴，直接子Marker3D Muzzle位于(0,0.02,-1.05)，组合射口为(0,0.78,-1.05)，所有组合一致。本批尺寸接口固定，后续更改需同步验证权威射口，禁止仅改美术。

HullMount与TurretMount独立旋转；炮塔位置取底盘接口，世界朝向只由瞄准状态决定，不能叠加车身朝向。更换采用先验证候选、再移除旧节点，禁止半装配。机库预览只选择和显示，不修改战斗或共享Resource，不保存未实现的武器配装到训练。

本批模型为代码原创基础低多边形视觉样件，可在Godot编辑器独立替换；不是最终量产美术。验收九种组合、射口一致、错误配置保留旧模型、重复更换不堆积、独立朝向、UI切换与离开释放。

010补充：三类攻击策略验收通过后，机库可通过app创建匹配配装的新训练会话；本接口的原预览限制不再阻止训练入口。模型仍只表现，不拥有碰撞/伤害，配装不写持久化存档。
