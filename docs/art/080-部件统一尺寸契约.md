# 080 部件统一尺寸契约

依据：用户明确要求所有炮塔之间、所有底盘之间比例与大小一致，仅造型不同。统一挂点不足以满足本要求；不同底盘不能再以外观尺寸表达载重或稀有度。

统一视觉尺寸（世界单位米，静止装配姿态，包含所有可见网格及程序化轮带）：

|模块类别|宽X|高Y|总长Z|
|---|---:|---:|---:|
|炮塔|1.32|0.68|1.90|
|底盘|1.65|0.847364|1.763323|

炮塔外廓下角为(-0.66,-0.016528,-1.10)，底盘为(-0.825,0,-1.056662)。底盘以已认可轻履带外廓为基准；炮塔采用共同尺寸，主战炮一并校准，避免把其余不同结构全部压到原主战炮0.458米高度。尺寸含炮管/喷口，不允许换武器或底盘后改变标准外廓。轮式、履带、炮口和储罐保留各自造型辨识；现有几何通过另存表现包装校准，新模型应直接按共同尺寸制作，以减少轴向校准造成的形状比例变化。

配置唯一来源：content/presentation/part_size.tres及presentation/part_size_style.gd。tools/normalize_part_sizes.gd从固定原场景测量并重建presentation/parts/unified_size_v1，calibration.json保存原尺寸、目标、轴向缩放与偏移，禁止以已校准场景重复累积缩放。源GLB、纹理及历史场景只读保留。

权威接口不缩放：最外层根identity，直接子Muzzle=(0,0.02,-1.05)、TurretSocket=(0,0.76,0)。只有Geometry分支缩放；独立后坐、完整轮组和履带仍绑定既有事件/状态，暂停冻结与生命清理继续有效。静态标准外廓不限制真实动画瞬间的移动范围；不得为满足截图边界裁掉后坐或轮带。

每次接入：通过tests/presentation/part_size_tests.gd的宽高总长及位置一致性回归（0.0002米误差），并运行完整tools/check.mjs。必须审阅十二混搭正背面、机库近景/旋转/缩放、训练正常尺寸与连续动作；卡片从统一尺寸模型独立渲染另存。Android门槛保留。
