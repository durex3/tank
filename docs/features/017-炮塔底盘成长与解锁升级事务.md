# 017-炮塔底盘成长与解锁升级事务

日期：2026-10-12；状态：本批实现与桌面验收通过。完整32项机库和技能尚未全部完成。

## 目标与分层
基础3炮塔/3底盘均支持1—10级显式成长表、金币解锁与升级。definitions/PartGrowthDef与ProgressionRules保存静态配置；content/growth保存六张表及初始补给；loadout/PartGrowth仅解析独立属性副本；profile保存版本2等级、金币、配装；session/EquipmentService校验并事务提交；HangarProgressPanel只显示和调用服务。

## 本项目首轮数值决定
这是独立试玩基线，不是复制MiniTanks经济。初始金币300，旧版v1档迁移一次到v2并保留原等级/配装；后续读取v2不补发。初始拥有仍只主战炮与轻型履带。速射80、散射100、侦察轮式100、重型履带160金币固定解锁；未实现部件拒绝解锁。暂无奖励产出，试炼不发币。

每级基础伤害/耐久按原提案约3%形成显式整数表，运行时只查表。升级费用为20/30/40/55/70/90/115/145/180。炮塔和底盘均在7级重量/承载提高1；其余等级保持。射速、射程、弹数、散布、加速、最高速和稀有度不变；技能尚未执行，不随升级虚构启用或成长。数据为首轮配置，未完成长期经济与跨级平衡验收。

## 接口与提交规则
PartGrowth.weapon/chassis(id,level)返回深复制定义，非法等级返回null；resolve供预览。EquipmentService.upgrade(id,expected_level)拒绝锁定、未知、满级、余额不足、过期等级及使已应用配装非法的升级。候选扣费与等级一起保存，成功才更换内存；相同旧expected_level重发不会重复扣费。unlock重复调用返回already_owned且不扣费，解锁不自动装备。

EquipmentProfile v2验证金币整数、非负和上限；v1迁移保留数据并加入初始补给。JSON数字读取使用数值比较版本，避免类型不同导致整数版本拒绝。存档恢复策略沿用016。

机库显示金币、费用、等级变化、伤害/耐久、重量/承载、超重和最终移速。左侧独立滚动，右侧坦克固定展示。训练开局注入等级快照，锁定试用为Lv.1；对局开始后不允许重新配置，不读取可变玩家档。旧基础训练调用默认Lv.1，回归保持。当前对练仍为无收益验证环境，不宣称正式战斗或经济完整开放。

载重仍沿用现有统一解析器（每超重1减速15%，最低60%，允许差值不超过2）。设计第15节20%与禁止超重2仍是未实施提案，本批不静默变更。
