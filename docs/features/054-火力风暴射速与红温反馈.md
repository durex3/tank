# 054-火力风暴射速与红温反馈

日期：2026-10-13。状态：桌面自动验收与实际渲染审阅通过；真人平衡及Android待验收。

目标：按用户试玩反馈及确认，提高速射大招节奏与强化弹辨识度，延长红温反打窗口；同步炮塔技能界面。

所属层与接口：BasicAbilityRules定义间隔、伤害倍率和散热时长；AbilitySystem提供damage_multiplier；WeaponAttack接收倍率，生成攻击前复制WeaponDef，保证射口即时命中与飞行命中伤害一致且基础资源只读。ProjectileState.storm_round保存每弹强化身份，脱离施放者后续状态；Presentation消费已提交状态及弹丸，不修改碰撞。Session与存档接口不变。

规则：窗口180tick不变，间隔由5改3tick，强化单发当前普攻×0.6，四舍五入至少1。Lv.1为15/发、20发/秒，稳定理论300HP/秒，与旧25×12相同；初始冷却、命中、整数取整影响实际输出。红温由36改90tick，期间禁火但可移动。松手停火、激活保留冷却、能量不自循环、死亡清理与暂停冻结沿用原契约。不是普攻积热系统。

表现：橙红短曳光弹及亮芯保留阵营尾标，长度0.65米、核心半径0.10米仅用于视觉。24段倒计时热量环、双侧热轨；散热改红色环、排热线及每实体两层烟，HUD显示剩余秒数和禁火状态。没有全屏闪光、全局时停或碰撞放大。瞬时精灵仍上限48；烟随死亡/离开阶段/结束清理，无提交tick时冻结。复用既有049烟雾/枪焰纹理和程序几何，无新增生图或覆盖美术资产。
