# 056-侦察脱险加速与烟幕验证

日期：2026-10-13。状态：桌面23项完整检查及实际渲染审阅通过；真人平衡与Android待验收。

目标：按用户确认让侦察被动提供直接脱险收益，并让移动训练靶可验证烟区减速；同步部件技能说明。

所属层与接口：BasicAbilityRules定义escape_ticks=90、escape_multiplier=1.25；AbilityState按实体/生命持escape_start_tick/escape_until_tick。AbilitySystem合法伤害批量提交后，与烟幕一起设置下一tick起的加速，统一组合载重后速度、施法限制及敌方减速；smoke_multiplier_at(position,team_id,tick)为坦克与训练靶共用只读查询。TrainingTarget.step_motion(speed_multiplier)按缩放后的每tick路程累积巡逻相位，避免乘总时间造成跳跃。UI只显示快照，Presentation只消费提交事件。

规则：非致死有效敌伤且600tick冷却就绪触发，加速最高自主移速25%、持续90tick；正常Lv.1侦察7.2→9米/秒。重复受击不刷新/叠层。原烟区半径1.6米、150tick、敌人移速65%不变，同源/异源减速不叠乘。加速不改变击退、普通攻击、护甲或子弹；蓄力速度限制仍乘算。死亡/重建清除，加速与烟幕暂停冻结；没有正式奖励或存档变化。

表现与美术：两侧三组薄荷绿流动箭头显示脱险阶段，HUD显示“脱险加速 +25%”与剩余秒数，结束显示冷却。沿用已有049烟雾贴图及来源；程序箭头尺寸/颜色写AbilityEffectStyle，无新增生图、无覆盖旧美术、无新碰撞。机库烟幕说明同步加速、冷却和不挡弹等实际行为。
