# 012-离线单局计分加时与结算重开

日期：2026-10-11。状态：实现、14项自动检查与Windows Compatibility实弹对局/截图检查完成；当前为1v1规则验证，Android与完整3v3待验收。

## 目标与已实现行为

从训练点击Start timed duel · 1v1创建全新对局，保留当前炮塔、底盘与控制模式，不带入练靶历史。独立offline_duel规则每队1车，复用原文4分钟、20分及最多30秒加时参数；标准standard.tres仍保持每队3人，未改写原始架构文档。

敌对参赛者有效击杀加1。全部伤害/死亡完成后汇总整tick比分：达到目标时领先队胜；双方同tick达标且同分进入加时。正常时间到时领先队胜，同分加时；加时一次批量得分后领先即胜，同tick互杀仍同分则继续，超时仍同分判平。截止tick的有效伤害纳入裁决。重复生命死亡、自毁、友军、训练靶及非参赛者不增加团队分。

死亡180tick后安全重建，比赛保护90tick，普通对练仍使用60tick保护。暂停冻结比赛和生命计时。结束禁用输入与后续模拟，不能通过Continue恢复。结算显示胜负、比分、双方击杀/死亡/实际伤害，未实现助攻或奖励时不显示虚假数据。

Rematch由app释放旧屏幕并创建新会话：新match_id、tick、HP、弹丸、输入控制器与统计；保留本次配装、设备模式及返回首页/机库的目的地。退出旧页面先stop再释放，防止残留会话运行。本批不发金币/经验。

## 分层、接口与变更文件

- definitions/match_rules.gd新增validate；content/rules/offline_duel.tres为双车规则，开局复制冻结。
- battle/match/match_runtime.gd：纯规则组件。configure冻结match_id、规则和ID→阵营名单；commit_tick接收已提交伤害批次，按实体/生命去重死亡，累计统计后判胜；snapshot返回独立副本。实例自身隔离match_id，死亡去重键不会跨局共用。
- battle/combat/damage_resolver.gd为结果补充life_index；battle/battle_simulation.gd在整个伤害批次之后调用赛制，结束后拒绝后续tick与双方输入。
- battle/combat/training_lives.gd复用已有安全重建机制，session注入比赛时长配置，避免复制另一套复活代码。
- session/movement_session.gd新增configure_match、比赛组装与FINISHED阶段；比赛不创建训练靶，双方明确为参赛伤害对象。会话消费match_finished清输入、更新epoch并冻结表现；保持暂停与结束独立。
- ui/widgets/duel_panel.gd只展示match_updated/match_finished，发起新局/返回请求。HUD按秒数、比分、阶段变化更新；结果面板使用Container布局、键盘焦点和旧确认键释放保护。
- ui/screens/movement_screen.gd接入面板和模式提示；ui/widgets/pause_overlay.gd支持对局暂停文字；app/bootstrap.gd组装新局并保留路由来源。
- tests/domain/match_cases.gd与tests/battle/match_tests.gd分开纯规则、实弹与导航回归；tools/check.mjs纳入第14项检查。tools/capture_match.gd生成实际画面证据。

规则先写入[012契约](../rules/012-离线单局与结算契约.md)，随后同步AGENTS.md、architecture.md、开发计划、功能索引及README。运行脚本均未超过300行，新函数未超过60行，无新增架构例外。

## 实际自动验收

最终执行node tools/check.mjs：架构守卫、版本、导入、领域、输入、移动、战斗、训练生命周期、战斗表现、部件、武器变体、对练、单局、启动共14项PASS。报告artifacts/check-report.json。

纯规则回归覆盖无效规则/名单、配置冻结、快照不能反改内部状态、重复死亡跨tick去重、新生命再次计分、自毁/友伤/非参赛者过滤、正常及加时截止tick得分、同tick互杀达标加时、加时互杀后继续、领先结束与超时平局。

实弹回归用真实ProjectileSystem和DamageResolver验证击杀分、120实际伤害、同tick双方死亡进入加时；结束后尝试恢复模拟或继续提交命令仍被拒绝。暂停冻结倒计时；比赛配置使用180tick复活/90tick保护，训练靶不加入比赛。

界面回归从机库散射炮/重履带训练，通过真实StartDuel、Rematch、ExitMatch按钮信号完成十次结算/重开；验证配装与触控模式保留、比分/满血/弹丸初始化、新match_id、旧会话释放、返回原机库。该项直接推进规则时钟以加速路由回归，不代表十场完整实战或3v3里程碑通过。

首次定向回归遇到测试变量类型推断错误，已显式标注；后续发现结算后立即重开会让延迟焦点操作作用于已离树按钮，已改为检查节点仍在树中才获取焦点。最终完整检查无这些错误，不以测试PASS文字忽略Godot ERROR。
