# 035-部件拼装外观与模型轮廓统一

日期：2026-10-12。桌面实现与验收通过；模型精细细节、Android待验收。

目标：限定已有3×3，以部件卡片为准，让换炮塔仅变炮塔、换底盘仅变底盘。采用用户最终要求的直接图片拼装；真实模型同步首轮轮廓调整。

所属层及接口：presentation/HangarArtCatalog.texture返回同卡片像素组合的1024透明纹理；HangarCompositionStyle管理固定取景与安装锚点；TankView.configure_parts验证候选后仅替换有变化的模块；领域和权威挂点不变。具体规则见docs/art/035-部件拼装外观契约.md。

变更文件：presentation/hangar_art_catalog.gd、hangar_composition_style.gd、tank_view.gd、tank_part_catalog.gd、parts/card_aligned六场景；content/presentation/hangar_composition.tres；ui/widgets/hangar_art_stage.gd；tools/build_card_aligned_parts.gd、capture_hangar_composition.gd、capture_hangar_model.gd、capture_tank_models.gd、export_part_references.gd、inspect_hangar_v2.gd；两组表现测试、文档。

实现：原底盘图与炮塔图朝向不同，翻转对称底盘后以固定图宽和逐部件安装点叠放，同一部件像素与比例稳定。用户反馈首轮炮塔偏大/偏高后，炮塔宽510→420（缩小约18%），底盘安装锚点y由0.24→0.28，使安装位置下移，已重新审阅九组合截图。九张独立整车生图会有细节漂移，按用户最终反馈放弃接入；候选与完整提示词保存artifacts/concept-candidates/hangar-v2/provenance.json。主界面仍默认静态拼装图，360度仅在真实装配模型入口。

真实模型：新增六独立场景，不覆盖原模型。六小轮履带、宽重履带、四轮底盘，棱角炮塔与三种炮管轮廓；中空环形炮口、弹带、分节履带与装甲片。五材质表面/部件，静态细节合并减少绘制提交；约3万—5.2万三角形/整车。工具重建一次类型数组赋值失败（虽输出PASS，但日志有SCRIPT ERROR，实际判为失败）；修复后重跑成功，无该错误。生成器长函数用于离线资源数据构建，不在运行时执行。

验收证据：Godot tools/capture_hangar_composition.gd PASS，实际审阅hangar-composition.png与hangar-composition-gallery.png，九组合部件一致；tools/capture_hangar_model.gd与capture_tank_models.gd真实Compatibility九组合、旋转与窗口缩放截图。新增可见下部底盘像素不变回归和未变部件实例保持回归。最终运行tools/check.mjs：21/21 PASS；git diff --check：PASS。

限制：2D拼装不支持旋转；锚点与对称镜像是表现拼装，不对应权威坐标。模型首轮对齐主要轮廓，仍比设定图简化，法线/纹理/装甲细节可继续完善。Android触屏、安全区、热稳定与3D性能待验收；不扩展未设计部件。下一编号036。
