# 034-机库模型预览清晰度

日期：2026-10-12。桌面实现与截图验收通过，Android待验收。

目标：保留现有模型改善机库真实3D预览的阶梯边缘与占比。

所属层及接口：UI SubViewport渲染与presentation摄像机；独立HangarPreviewStyle Resource供两者只读使用。无领域或战斗逻辑改动。

变更：ui/widgets/hangar_art_stage.gd、presentation/hangar_preview.gd、presentation/hangar_preview_style.gd、content/presentation/hangar_preview.tres、tools/capture_hangar_model.gd、计划及索引。

实现：仅机库开启4x MSAA、1.5倍双线性3D渲染缩放与线性视口纹理过滤；正交尺寸3.6→2.9，模型展示占比约提升24%；隐藏预览不持续渲染。参数位于Resource，不修改模型挂点或战斗画质。

验收：Godot tools/capture_hangar_model.gd实际Compatibility渲染，九组合截图均审阅，1280×720前后对比、旋转与1600×900截图已检查；主体与炮口未裁切。tools/check.mjs 21/21 PASS，git diff --check通过。一次沙盒图形启动exit134，提权重跑截图成功。

证据：artifacts/model-preview-before.png、model-preview-after.png、model-preview-large.png与model-部件组合.png。

限制：清晰度提升不等于造型对齐；用户进一步确认部件卡片为唯一造型基准，模型和整车图的统一作为035执行。移动端GPU开销与真机效果待验收；4x MSAA与超采样会增加机库渲染成本。下一编号035。
