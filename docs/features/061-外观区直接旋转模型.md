# 061 外观区直接旋转模型

日期：2026-10-13。状态：桌面实现与验收通过，Android待验收。

## 目标、层与接口

按用户要求取消机库“查看装配模型/返回外观预览”切换，已有真实模型直接在外观区展示并拖动360°旋转。属于UI与presentation，无领域行为变更。HangarArtStage.show_loadout负责实际组合显示，show_design负责未就绪部件静态设计；TankPartCatalog、TankView及权威接口不变。后续用户生成已有部件按稳定ID逐件替换。

## 变更文件

ui/widgets/hangar_art_stage.gd移除切换按钮与静态平台装饰，默认显示真实模型，支持鼠标/触摸旋转并在切换/释放清除拖动。ui/screens/hangar_screen.gd对待开发部件调用show_design，禁止保留上一组合造成误解。tests/presentation/hangar_art_tests.gd改验直接预览，覆盖静态回退、禁止静态旋转、切换清拖动、外部触摸释放。tools/capture_{hangar_model,bubble_model,imported_models}.gd移除旧切换依赖。AGENTS.md、docs/rules/architecture.md、docs/art/035-部件拼装外观契约.md同步用户新规则；开发计划与功能索引同步。
