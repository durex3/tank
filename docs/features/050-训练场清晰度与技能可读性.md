# 050-训练场清晰度与技能可读性

日期：2026-10-12。状态：桌面22项完整检查与实际截图审阅通过；Android待验收。

目标：解决训练场坦克偏小、地面过亮及无抗锯齿导致技能不明显的问题。依赖042—049六能力；不扩展武器、对局或修改技能数值。

所属层与接口：UI负责独立SubViewport和显示缩放；TrainingViewStyle Resource持渲染尺寸、MSAA与灯光设置；CameraTuning持取景；ArenaDressing及GrayboxArena仅改视觉颜色。屏幕输入通过容器逆变换映射到实际渲染坐标，继续使用CameraRig地面投影；碰撞、射口、技能半径与模拟tick不变。

变更文件：presentation/training_view_style.gd、presentation/arena_dressing.gd、content/camera/fixed_arena.tres、session/graybox_arena.gd、session/movement_session.gd、ui/screens/movement_screen.gd、tests/presentation/battle_visual_tests.gd；本记录、开发计划与功能索引。
