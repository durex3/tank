状态：实际渲染审阅通过，完整30/30检查通过；用户观感与Android待验。

## 目标与层级

开发120期间用户补充速射大招缺少受击效果。补齐真实命中后的橙红火花与短暂装甲闪色；连续扫射时限频，避免覆盖目标轮廓。领域仅补来源元数据，不改变伤害或射击节奏。

## 接口与变更文件

- `battle/projectiles/projectile_system.gd`：风暴弹飞行命中携带ability_id=storm。
- `battle/combat/weapon_attack.gd`：体内到枪口扫掠的即时命中同样补storm身份，不漏近距离受击。
- `presentation/skill_flipbook_effects.gd`：消费实际damage_applied，按目标最多每6tick播放一次橙红火花，仍遵守全局特效预算。
- `presentation/tank_hit_flash.gd`、`tank_view.gd`：风暴受击轻微橙色闪光持续3tick，每6tick允许一次，存在明确恢复间隔；不让每3tick一发的子弹将整车长期染色。
- `definitions/skill_flipbook_style.gd`：独立命中尺寸0.75米、限频、持续时间和颜色。
- `tests/presentation/ability_vfx_tests.gd`：重复/快速连续命中限频、恢复间隔、6tick边界再次触发。

仅特效限频，真实伤害仍逐发正常提交；敌友、保护期及生命过滤由原DamageResolver负责。暂停无提交tick则表现冻结，结束清理。
