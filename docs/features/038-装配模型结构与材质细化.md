# 038-装配模型结构与材质细化

日期：2026-10-12。状态：桌面验收通过，Android待验收。

目标：依据已有部件卡片，细化真实装配模型，改善圆饼侧板、轮组重叠、炮口无厚度及白装甲缺乏层次的问题。仅已有三炮塔×三底盘；静态拼装外观维持037。

所属层与接口：presentation。TankPartCatalog映射新增card_detailed六个独立PackedScene；TankView.configure_parts接口、独立旋转/候选校验/仅替换变化部件的行为保持。TurretSocket(0,0.76,0)、Muzzle(0,0.02,-1.05)、根单位变换及无碰撞契约保持，不修改领域、武器和载重。

实现：炮塔使用挤出棱角护板、窄倒角、分层外板、前额装甲、后部检修盖/百叶、顶部缝隙/散热、光学镜片/边框、弹带及天线。炮管提供真实管壁、内衬、凹入炮膛、厚金色炮口、根部套环和螺栓。履带两端大轮与四个小轮错开高度和间距，增加内盘/金圈/辐条/轴心、回程轮和分节履带筋；轮式增加轴、悬挂杆、弹簧和分块胎纹。底盘增加斜车头、嵌板、格栅、分层挡泥板、重型梯形裙板、拖环、尾排气与引擎散热格栅。

材质与灯光：七共享材质区分白装甲、装甲边层、深机械、橡胶、钢、金色和绿镜片；机库独立主光/补光/轮廓光，仅主光投影，天空只用于反射，背景改为与机库接近的深色。灯光能量/背景/平台颜色由HangarPreviewStyle管理，不改变战斗灯光。离线按材质合并、每部件7表面，整车14表面；平面删除不影响轮廓的中心细分。精确三角形见presentation/parts/card_detailed/provenance.json，约5.4万—7.9万/整车，不代表Android性能已通过。
