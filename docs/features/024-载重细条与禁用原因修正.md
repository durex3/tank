# 024-载重细条与禁用原因修正

日期：2026-10-12。桌面检查完成，Android待验收。

用户截图显示载重条过粗，根因是共享ProgressBar样式含14像素内容边距，覆盖了12像素的目标高度。改为零内容边距的专用StyleBoxFlat，细条保持12像素，外层胶囊独立布局。超重时填充与数值变红。

操作区收紧按钮高度，禁用按钮增加明确深色边框及文字颜色。金币不足时按钮和状态文字明确说明；超重展示实际值，只有LoadoutResolver.can_save拒绝时显示无法装配，不把可减速装配误报为禁装。黄色条仅用于升级后超重；无负面影响时保留同高透明占位，避免状态切换让预览跳变。

修改ui/widgets/hangar_art_stage.gd、hangar_details_panel.gd和ui/screens/hangar_screen.gd。仍消费服务和领域解析结果，不改动金币或载重规则。页面增长已超过300行，下一次新增操作区功能应先提取独立组件；本批完成当前缺陷修复，未引入领域公式。

验收：node tools/check.mjs，21项PASS。修复操作行最小高度不足导致的2像素预览跳变后重新全部通过。实际审阅artifacts/workbench-chassis.png：细载重条、解锁按钮与费用、未拥有状态及禁用应用按钮可见。
