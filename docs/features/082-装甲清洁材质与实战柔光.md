# 082 装甲清洁材质与实战柔光

目标：改善用户对照图中装甲碎斑、光照偏平、脚下标记抢眼的问题，保留081统一尺寸及已认可造型。所属层：presentation；session仅组装表现灯光。

接口：TankSurfaceStyle增加局部碎斑清理、接触阴影尺寸/透明度和阵营圈宽度/透明度；TrainingViewStyle增加补光方向、颜色、能量。均为只读表现Resource，不影响碰撞、射口、伤害或能力范围。

变更文件：presentation/shaders/clean_armor.gdshader、contact_shadow.gdshader；tank_surface_polish.gd、tank_surface_style.gd、tank_view.gd、tank_health_view.gd、training_target_view.gd、training_view_style.gd；content/presentation/tank_surface.tres、training_view.tres；session/movement_session.gd；hangar_part_art_catalog.gd；tests/presentation/tank_parts_tests.gd；tools/capture_surface_finish.gd、capture_finish_icons.gd、capture_finish_gallery.gd；assets/derived/clean-finish-v1。

实现：亮中性漆面清理提高至0.90、法线降至0.18；使用粗一级邻域颜色减弱孤立中性碎斑，保留成片深色机械件、金色和光学颜色。漆面调整为中性白哑光；ORM遮蔽只轻度混合，避免重新压黑。材质遍历整个部件，包括081独立轮组，各实例独立覆盖，不改源纹理。训练新增无阴影低强度冷色补光，降低环境光与主光；TankView增加无碰撞软边接触阴影，随实体可见性/生命周期释放。阵营圈变细、透明度降低，未改变范围提示或判定。七张卡片由同一材质重新渲染并另存。

验收命令：`env GODOT_BIN=/Applications/Godot.app/Contents/MacOS/Godot node tools/check.mjs`。首轮失败：新增ContactShadow暴露了旧测试将所有直接子节点当装配挂点的假设，改为明确检查HullMount和TurretMount，并补阴影为纯表现及销毁检查；卡片切换发生于首轮运行中，未完成纹理导入造成相关脚本加载失败。导入完成并修正测试后完整重跑，27项全部通过；artifacts/check-report.json passed=true。

实际渲染：tools/capture_surface_finish.gd已捕获主炮/散弹/机炮正常游戏视角并审阅；工具只隐藏截图暂停遮罩，不修改正式失焦暂停行为。tools/capture_finish_gallery.gd捕获并审阅12组合。七张卡片、机库完整界面及旋转视角已实际截图并审阅（artifacts/imported-preview-after.png、imported-preview-rotated.png）；实战截图artifacts/finish-cannon.png、finish-scatter.png、finish-autocannon.png。

状态：桌面自动检查与实际渲染审阅通过，Android待验收。限制：原网格中的成片机械深色细节保留；局部纹理清理不等于重新手绘贴图。新增每像素一次邻域采样、每车一张透明阴影面和全场一盏无阴影补光；Android真实帧率、热稳定及触屏仍待真机验收。原始资产、081派生模型与旧卡片不覆盖，未调用外部生成服务。
