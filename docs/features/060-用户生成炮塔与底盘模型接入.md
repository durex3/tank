# 060 用户生成炮塔与底盘模型接入

日期：2026-10-13。桌面接入与自动验收通过，Android待验收。

## 目标与所属层

将用户提供的Tripo主战炮塔、轻型履带GLB接入已有稳定ID，支持机库真实模型预览和训练表现。仅presentation与资源层；原图、原模型、数值、存档与领域定义不改。

## 接口与装配

TankPartCatalog仅替换cannon/light_tracks映射，其他部件保持原场景。新包装场景根变换为identity，直接子Muzzle=(0,0.02,-1.05)、TurretSocket=(0,0.76,0)不变，无脚本、碰撞或战斗逻辑。GLB仅在Visual子节点校准：炮塔绕Y转180度，缩放(1.3,1.2,1.65)，偏移(0,-0.3976,-0.225)；底盘缩放(2.1,1.6,2.1)。两个生成模型均归一化过，因此按既有权威接口独立调整可视比例，非模型物理尺寸。炮口前缘约在-Z=1.05米，口中心高度对齐既有射口；不改变权威坐标。

## 变更文件

- assets/imported/tripo-v1/{cannon,light_tracks}.glb及导入配置、provenance.json：原下载二进制原样复制，记录SHA256、来源及缺失信息。
- presentation/parts/tripo_v1/{cannon,light_tracks}.tscn：独立场景包装。

- docs/development-plan.md、docs/features/README.md、本记录。
