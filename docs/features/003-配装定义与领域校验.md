# 003-配装定义与领域校验

日期：2026-10-11。状态：基础领域完成。

## 目标与所属层

依据基线第5/9章定义数据与唯一配装公式，为后续机库、训练和战斗复用。definitions/content只读，loadout产生独立ResolvedStats，core定义时间与输入契约。

## 接口与变更

- WeaponDef：伤害、精确冷却、射程、弹速、弹丸数、散角、载重、技能ID与nominal_dps。
- ChassisDef/AbilityDef/MatchRules：底盘、技能基础参数和标准赛制。
- content/weapons、chassis、abilities、rules：三炮塔、三底盘、三技能与标准战tres。
- LoadoutResolver.resolve(weapon, chassis) → ResolvedStats；can_save验证超载不大于2。
- BattleClock.seconds_to_ticks：60Hz，向上取整且至少1tick。
- PlayerCommand/InputSource：意图字段与sample/cancel_pending契约，当前未实现触控。
- ContentValidator.validate：检查重复/空ID、技能引用、伤害载重、冷却射程弹速、散角、弹丸预算与底盘合法性。
- tests/domain/run_tests.gd：领域边界测试。
