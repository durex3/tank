# 129 重型穿甲炮轮廓与重量打磨

状态：桌面32项检查和真实训练96帧采集通过；用户已确认当前主炮样板。Android待验收。

## 目标、层级与接口

在128分层样板上打磨主炮轮廓：不等长接触瓣代替规则星形，圆钝亮头和按米计算的短尾代替箭头，碎片略加大并保留旋转与落下重量。仅表现层；稳定ID、瞬时贯穿、伤害、射程和既有后坐不变。

## 变更文件

- presentation/shaders/toon_contact.gdshader、toon_fx_materials.gd：枪口、命中与准备亮点独立形状参数，三段色块和边缘抗锯齿。
- presentation/shaders/armor_piercing_trace.gdshader、ability_signature_effects.gd：注入实际路径长度，圆钝亮头、短尾与淡余迹；仍由提交tick驱动。
- presentation/ability_sprite_effects.gd：枪口选择独立轮廓。
- presentation/toon_particle_group.gd、content/presentation/skill_flipbooks.tres：交替碎片旋转、较少缩小、24tick抛落和较淡尘烟。
- tools/capture_cannon_weight_129.gd：四炮塔各24帧真实训练采集，重点覆盖主炮准备、出膛、命中、飞散与退场。
