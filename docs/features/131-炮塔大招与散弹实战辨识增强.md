# 131 炮塔大招与散弹实战辨识增强

状态：桌面33项完整检查、205帧真实训练采集、三背景15组像素检查通过；最终用户观感与Android待验收。

## 目标、层级和接口

用户反馈机炮/主战炮大招看不清、散弹弹丸不明显，泡泡普攻可接受而大招不足，要求整体更明显。沿用godot-shaders、game-feel与既有类型化GDScript规范，仅改表现及其Resource/测试工具；不改battle/session、普通泡泡表现、伤害、碰撞、技能射程、模拟时长和预算。

## 实现与变更文件

- 主战炮：亮头掠过后留下0.38米基准宽度的暖金贯穿残影，采用清楚的暖白/金色/深橙色带，减缓前段透明衰减、末段退出；保留14tick表现与瞬时穿刺。枪口爆闪增大。文件：presentation/shaders/armor_piercing_trace.gdshader、ability_signature_effects.gd，definitions/weapon_visual_style.gd及content/presentation/weapon_visuals.tres。
- 机炮大招：短弹迹长度0.65→1.25米，几何半宽配置0.10→0.28米；大招枪口宽1.35→1.9米，短闪4tick，保留连续开火节奏；持续机械亮点由很小的半透明点改为更清楚的暖色提示。只增强大招，普通连发时序不变。文件：presentation/ability_sprite_effects.gd、ability_signature_effects.gd及AbilityEffectStyle/ability_effects.tres。
- 散弹：角形弹丸视觉半径0.105→0.19米，独立铜金色主体提高与沙地对比，较粗短尾和短亮迹帮助辨认五发扇面。仍沿提交方向，无额外弹丸或碰撞。文件：presentation/weapon_projectile_visual.gd、WeaponVisualStyle及weapon_visuals.tres。
- 泡泡大招：抛投体单独放大两倍，普通泡泡尺寸、shader和寿命算法保持原样；落地增加一次贴地扩散波，中心水花及三个水滴加大；水域填色和边缘增强，全部限制在原权威半径内，最终退场淡出不变。文件：presentation/bubble_visual.gd、bubble_bursts.gd、combat_view.gd、shaders/toon_fx.gdshader与新增toon_water_landing.gdshader，AbilityEffectStyle。
- 修复真实缺陷：bubble_lob在飞行期lifetime_ticks尚为0，旧表现用max(1,lifetime_ticks)计算life，飞出一帧后即进入完全淡出；现按arc_ticks表达飞行阶段，保持可见到落地。弧线尾滴使用已提交position/previous_position；不写回ProjectileState。

新增的落地波只是一次落地效果的组成部分，不重复堆叠完整水花，不添加侧立面。资源实例材质独立；按提交tick解析变化，无TIME或delta生命周期。
