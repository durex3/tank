# 002-分层架构与代码规范

日期：2026-10-11。状态：完成。

## 目标与所属层

将原始架构约束变成每次开发必须读取的本地规则，避免入口、HUD与全局单例堆积逻辑。所属：工程治理与tools。

## 变更与接口

- AGENTS.md：每次开发读取顺序、实现/检查/记录流程、技能与资源使用约束。
- docs/rules/architecture.md：模块职责、依赖方向、状态所有者、场景组合、会话与Autoload限制。
- docs/rules/code-style.md：类型、命名、文件体积评估、错误处理、测试与美术规则。
- tools/check.mjs：检查版本、基础领域依赖禁区、脚本导入、领域测试、启动冒烟，写JSON报告并以退出码失败。
- docs/development-plan.md、README.md、docs/features/README.md：状态与开发入口。

## 验收

node tools/check.mjs实际执行，五项检查PASS。守卫扫描core/definitions/loadout内显式res路径与常见场景/设备访问；不能替代代码审查，也不声称检测所有class_name隐式依赖。

## 限制与下一步

后续模块出现时扩充依赖守卫。规则变更必须同步文档；每项功能完成即时写NNN记录。Android与网络不在本次验证范围。
