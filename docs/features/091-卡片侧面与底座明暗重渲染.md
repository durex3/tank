# 091 卡片侧面与底座明暗重渲染

日期：2026-10-15。状态：桌面渲染审阅通过；用户观感与Android待验收。

目标：用户否决088观感，并提供其他游戏参考截图。提取炮口内壁、侧装甲与底座分层的特点；不复制其模型资产。

所属层：presentation离线卡片摄影及UI素材映射。接口：PartCardRenderStyle新增立面/高度明度参数；card_volume shader仅用于离线摄影，不改战斗材质、权威射口或模型尺寸。七件现有模型另存volume-cards-v2，HangarPartArtCatalog切换到新版。

变更文件：presentation/part_card_render_style.gd、presentation/shaders/card_volume.gdshader、presentation/hangar_part_art_catalog.gd、tools/capture_volume_cards_v2.gd、assets/derived/volume-cards-v2七张PNG。来源见../art/091-卡片重渲染来源.md。

验收命令与实际结果：Godot执行tools/capture_volume_cards_v2.gd PASS，1024px四倍MSAA渲染后缩至512px。首次执行capture_hangar_workbench.gd出现新PNG尚未导入的preload错误，虽然工具打印PASS且退出0，该次作废；tools/check.mjs完成editor import后重新执行，无脚本错误。实际审阅炮塔页、底盘页及部件单图，侧面与底座明暗可辨。滚动、详情与升级由同工具留图并另行审阅。完整回归结果见development-plan.md。

限制：原模型轮廓仍偏低矮，卡片占位偏小，与参考图的高体积轮廓仍有差距；本次没有用非等比拉伸伪造体积，没有宣称已达到参考品质。PNG是模型渲染卡片，不是3D资产。下一步：用户审阅并决定轮廓设计与卡片空间调整；Android字体/采样待验收。
