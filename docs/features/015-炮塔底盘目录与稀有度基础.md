# 015-炮塔底盘目录与稀有度基础

日期：2026-10-12；状态：目录层验收通过，完整机库基础系统仍在开发。

## 目标与层次
将设计中的22炮塔和10底盘登记为可查询、可校验的Resource目录。definitions保存PartEntry/PartCatalogDef，content保存32项静态数据，loadout的PartCatalog只负责查询与验证，不持有玩家状态。

## 接口与规则
PartCatalog.find按稳定ID查询，未知ID返回null；entries_of按炮塔/底盘分类；validate检查重复ID、必需字段、稀有度及已实现条目对应的玩法定义。炮塔ability_role为ultimate（大招），底盘为passive（被动），分别记录就绪状态。当前全部技能仍未实现，不显示已生效。

四档稀有度来自设计第14节。初始赠送只标记cannon和light_tracks；普通不等于已拥有。basic_ready仅指已验收基础普通攻击/移动的6个部件，不代表技能或正式配装整体就绪。其余26项是目录预留，不进入LoadoutCatalog现有训练列表。unlock_rule_id仅为稳定引用，任务与价格未落地，禁止据此直接发放部件。
