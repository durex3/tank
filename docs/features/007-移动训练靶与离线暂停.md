# 007-移动训练靶与离线暂停

状态：实现与Windows自动检查完成；Android生命周期和多指操作待验收。

## 目标与所属层
中间670HP训练靶以2m/s沿X轴往返±2.5m，其他靶保持静止。battle负责固定tick运动与即时碰撞同步；session拥有RUNNING/PAUSED/STOPPED状态；input处理清零和旧按键隔离；presentation冻结动画；ui显示暂停面板。

## 接口与变更
TrainingRules新增运动范围/速度和配置校验；TrainingTarget.step_motion/reset_motion同步AnimatableBody3D及伤害区域。BattleSimulation.set_paused冻结tick、弹丸、重建与命令接收。MovementSession.pause/resume/stop统一生命周期，恢复更新控制器epoch且保留冷却。TankMotor.halt停止速度。DesktopInputSource恢复后要求旧方向键先松开；PauseOverlay吞掉打开前遗留的释放事件。CombatView.set_paused冻结Tween。MovementScreen提供Esc/暂停按钮和显式继续。

主要文件：definitions/training_rules.gd、battle/actors/training_target.gd、battle/battle_simulation.gd、session/movement_session.gd、input/desktop_input_source.gd、presentation/combat_view.gd、presentation/training_target_view.gd、ui/widgets/pause_overlay.gd、ui/screens/movement_screen.gd、tests/battle/training_lifecycle_tests.gd。
