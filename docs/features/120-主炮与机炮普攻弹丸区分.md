# 120 主炮与机炮普攻弹丸区分

状态：实际渲染审阅通过，完整30/30检查通过；用户观感与Android待验。

## 目标与所属层

用户确认主战炮普攻表现为有分量的实体炮弹、速射炮普攻表现为独立快速曳光。仅presentation改动，不调整伤害、弹速、射速、碰撞半径。

## 接口与变更文件

- `presentation/weapon_projectile_visual.gd`：主炮采用深色圆头短粗金属弹体、深色束带和短尾焰；机炮普通弹降低亮度，短尾迹采用透明材质。
- `definitions/weapon_visual_style.gd`：炮弹半径0.12米/长度0.46米；普通机炮弹长0.44米、尾迹0.34米；大招曳光长度独立保留0.9米，防止普通弹调整误改大招。
- `presentation/shaders/projectile_glow.gdshader`：主炮短暗橙尾焰，取消白亮能量拖尾。
- `presentation/combat_view.gd`：火力风暴读取独立曳光配置。
- `presentation/skill_flipbook_effects.gd`与`ability_sprite_effects.gd`：普通主炮命中使用既有生成装甲火花与小烟尘，避免重复叠加旧爆点。
- `tests/presentation/weapon_identity_tests.gd`：保留弹丸身份、方向与尾迹朝向回归。
- `tools/capture_weapons_120.gd`：真实普通主炮/普通机炮/火力风暴射击和命中阶段截图。
