# 085 四炮塔普攻与大招视觉辨识

日期：2026-10-14—15。目标：解决主炮、机炮、散射共用小球/枪焰造成的同质化，并提高大招准备与释放的辨识度。所属层：presentation；battle仅补冻结武器身份与事件元数据，不改数值或判定。

设计与接口：见docs/design/085-四炮塔普攻与大招视觉重设计.md。ProjectileState.weapon_id创建时冻结；命中带weapon/direction/ability_damage/storm，出膛带方向。WeaponVisualStyle只读持有尺寸/贴图/时长/预算。WeaponProjectileVisual创建粗弹带炮弹、细针曳光、棱角散射片；泡泡保留膜球。AbilitySignatureEffects消费提交tick，增加聚能双环/释放扩散环、过载双喷流、扇形三波前与碎片、五落点分段充盈。普攻枪焰/命中有独立宽度与轮廓；主炮命中使用新生图。

变更文件：battle/projectiles/projectile_state.gd、projectile_system.gd、battle/combat/weapon_attack.gd；definitions/weapon_visual_style.gd、content/presentation/weapon_visuals.tres；presentation/weapon_projectile_visual.gd、ability_signature_effects.gd、combat_view.gd、ability_effects.gd、ability_sprite_effects.gd；tests/presentation/weapon_identity_tests.gd、tools/check.mjs、tools/capture_weapon_identity.gd；assets/generated/vfx/weapon-identity-v1及相关文档。

美术：内置image_gen生成单张主炮碎片冲击图；源1254×1254 RGBA、派生512×512，alpha 0—255，提示词/provenance与原图均保留。PNG仅为命中贴图，弹体为真实无碰撞几何。独立炮弹最多四网格；新技能瞬时根上限24、持续演员根上限24；透明贴图继续受既有48上限，新几何按提交tick销毁。未引入全屏后处理/时间缩放或权威位移。
