# 071 轮组动画候选与短炮管

日期：2026-10-14。状态：短炮管接入；轮组候选视觉失败，已撤回底盘运行映射，不标记完成。

## 目标、层与接口

按用户要求试做六轮盘旋转、履带表面滚动及炮管缩短20%。属于presentation及派生资源，TankTracks只消费已提交位置、朝向与tick，暂停不推进；死亡/重建/结束清基线与相位。无权威速度/射口/碰撞变化。

## 文件与实际结果

- tools/derive_rodin_motion_parts.py、assets/derived/rodin-motion-v1/：圆形轮盘面切分，UV/法线插值，原图只读；最终候选底盘23180、炮塔9948三角形。缩短炮管保持套筒接点和独立后坐枢轴；壳体不缩短。
- presentation/parts/rodin_motion_v1/：候选场景。tank_part_catalog.gd仅炮塔使用短版，轻履带恢复070原版；部件卡片对应各自实际版本。
- presentation/tank_tracks.gd、tank_view.gd、tank_motion_style.gd、shaders/clean_armor.gdshader：位移/转向差速、独立轮盘与履带表面纹路滚动。不是逐片几何履带动画。
- tests/presentation/tank_motion_tests.gd：候选显式注入测试，不默认启用有瑕疵底盘。覆盖前进、倒退、转向、堵墙不空转、相位停止、重复tick、真实会话移动及暂停、实例隔离、死亡、传送与换底盘。
- tools/capture_track_motion.gd、capture_track_icons.gd：96帧顺序、独立卡片；artifacts/track-frames与track-motion.gif为候选观察证据。
- 初版完整检查24/25，后坐枢轴被缩短变换影响导致既有复位断言失败；改为子网格变换后25/25通过。
- 连续帧实际审阅：切分区域卷入金色边缘，缩小圆形范围仍有错边，未通过视觉验收。不能以自动测试通过声称轮组完成。
