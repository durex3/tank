# 090 转向制动与速度衔接

日期：2026-10-15。状态：桌面回归通过；真人手感与Android待验收。

目标：回应用户对089转向手感的质疑，减少车头尚未转过去、车身已高速横滑的观感。保留WASD屏幕方向移动、鼠标独立瞄准。

所属层：definitions/content规则；battle运动。接口：TankSteeringRules提供转速、朝向对齐速度曲线、转向制动加速度；TankMotor先转向再计算自主目标速度。180度仍沿命令偏好消歧，其余最短路。强制位移在自主速度之后合成，不受此曲线缩放。

变更文件：definitions/tank_steering_rules.gd、content/rules/tank_steering.tres、battle/actors/tank_motor.gd、tests/battle/steering_feel_tests.gd、tools/check.mjs。设计见../design/090-转向速度衔接与卡片体积优化.md。

当前参数：7.5rad/s，180度约26tick；未对齐最低目标速度15%，对齐恢复原速度；转向/松手制动40m/s²。自主方向仍跟输入，不改为汽车操控。有限转向会影响正面装甲的实际朝向时机。

验收实际结果：Godot headless执行tests/battle/steering_feel_tests.gd PASS；检查满速6m/s、反向首tick立即制动、10tick低速、60tick恢复反向满速、10tick松手停止、90度起步、强制8m/s不缩放及halt。tools/capture_turn_paths.gd PASS，实拍左右反向各6帧；第10tick均经过屏幕上方，第30tick已朝目标，鼠标aim保持相同。旧移动碰墙/输入超时、暂停、独立瞄准由完整回归继续覆盖。

限制：截图与数值不能证明真人手感。新制动明显更快，连续变向是否过硬、轮式底盘是否需要差异化转速仍待试玩；没有宣称M1或Android通过。下一步：用户实机体验与移动端触控验收。
