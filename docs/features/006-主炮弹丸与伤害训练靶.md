# 006-主炮弹丸与伤害训练靶

日期：2026-10-11。状态：实现、桌面自动测试与实际渲染检查完成；Android真机待验收。

## 目标与所属层

依据架构文档第9/11章和T005/T006，实现主炮从输入意图、权威冷却、弹丸碰撞、伤害结算到视觉/HUD反馈的完整训练链路。保持input→session→battle→events→presentation/ui边界。当前只实现cannon，不声称三炮塔均可用。

## 接口与模块

- WeaponController.poll(command, tick, interval)：单发request_id单调去重，tick冷却；最多等待6tick，过期明确拒绝；cancel_pending清缓冲，不清既有冷却。
- ProjectileSystem.spawn/step：独立弹丸数据、每tick前后位置射线扫掠；主炮120伤害、0.8秒/48tick、14米、24m/s。中心到1.05米权威枪口先扫掠，起点内部命中启用hit_from_inside；避免枪口穿墙与高速穿薄墙。
- ProjectileState：projectile/owner/request/tick/lifetime/team及轨迹，不携带视觉节点。128活跃弹丸上限，超预算发明确拒绝；没有静默丢伤害。
- DamageableState/Damageable：受击状态与Area3D适配；同实体多受击体共享状态。WorldSolid(1)/Damageable(4)构成查询mask5，友军和尸体hurtbox被排除后继续查询。
- HitEvent/DamageResolver.resolve_batch：同tick收集、按projectile_id排序、projectile/entity/life去重；过滤保护、友军、尸体和旧life；实际扣血不超过剩余HP。弹丸首次命中即回收，避免跨tick重放。
- TrainingTarget：独立实体ID、350/670/1445HP实体，零奖励/能量；击毁后180tick重建并递增life_index。HP、位置和重建时长存TrainingRules/content/training/default.tres。
- BattleEvents：每会话事件ID递增，包含match_id、tick、source_id、target_id；提供weapon_fired/projectile_hit/damage_applied/entity_died/entity_respawned/cooldown_changed/fire_rejected。
- CombatView/TrainingTargetView：可见弹丸、短闪光、目标血量标签；UI通过事件更新伤害提示和冷却条。

## 操作

运行工程 → Drive & fire · training。WASD/方向键移动，鼠标瞄准，松开鼠标左键或空格发射一次。Touch controls启用后，右摇杆松手开火，左摇杆同时移动；系统取消不射击。近距离连续提前松手若超过100ms冷却容错窗口会提示拒绝，请等待冷却条充满。

## 限制与下一步
