# 081 部件比例与圆形轮组修正

目标：修复080整件三轴缩放造成的主炮过高、重履带椭圆及侦察轮转动变形。所属层：presentation与离线美术工具。

接口：TankPartCatalog稳定ID和直接Muzzle/TurretSocket不变；统一外廓仍读取content/presentation/part_size.tres。原始模型及080派生资源保留。

变更：tools/calibrate_part_proportions.gd基于原始装配场景重新派生presentation/parts/proportion_v1七场景。主炮X/Y采用同一缩放，独立暗色安装环补齐高度；重履带车壳单独校准，轮带采用首套底盘尺寸、保留四轮结构；侦察四轮从非等比车壳中分离，保持刚性世界坐标变换并重新定位。其他三炮塔与轻履带外形校准延续080。卡片使用assets/derived/proportion-v1实际模型渲染。测试新增四角度轮轴等长及正交检查，防止只在静止时圆。

变更文件：上述工具、场景、图像；presentation/tank_part_catalog.gd、hangar_part_art_catalog.gd；tests/presentation/part_size_tests.gd；规则与计划索引。

验收：本机桌面检查通过。首次直接node tools/check.mjs因锁定路径为Windows exe而ENOENT失败；随后执行`env GODOT_BIN=/Applications/Godot.app/Contents/MacOS/Godot node tools/check.mjs`，27项全部通过。尺寸最大容差0.0002米，四轮轴角度检查通过。

视觉：已审阅12组合实际渲染图，主炮高度恢复、重履带轮组恢复圆形；已审阅重履带与侦察轮组运动序列的起始、中间、结束帧，轮纹/轮面转动且未被接入缩放拉成椭圆。未声称Android真机验收。没有重新生成3D模型；独立底座为真实三维几何。

限制：AI原网格可能有细微非规则曲面，轮轴检查保证接入不额外引入椭圆，不代表原网格数学上完美圆；本次不重建其他三炮塔的原始造型。后续以用户实机审阅调整。
