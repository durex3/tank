# 067 主战炮独立炮管后坐

日期：2026-10-13。状态：实现、自动回归与样板静态实拍通过；连续动画观感、三底盘全角度动态及Android待验收，不标记完整美术验收完成。

## 目标、所属层与接口

保留用户确认继续使用的原主战炮造型，派生切分前部炮管并接入独立后坐，不使用066智能网格候选。属于presentation/派生资源及session提交事实接线；领域和战斗参数不变。

TankView新增entity_id、on_event、advance_visual_tick和reset_visual_motion；TankRecoil每视图独立持有枢轴与动作状态。MovementSession/SparringSession注入实体身份，消费既有weapon_fired/ability_fired、生命与结束事件，在快照提交后推进表现tick。炮管后退不改变Muzzle、炮塔壳体、碰撞和弹丸出生。
