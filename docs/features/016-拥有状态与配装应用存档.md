# 016-拥有状态与配装应用存档

日期：2026-10-12；状态：本批验收通过，完整机库基础系统未全部完成。

## 目标、层与接口
profile/EquipmentProfile持有等级字典及已应用稳定ID；EquipmentStore负责版本1 JSON和恢复；session/EquipmentService负责应用验证和保存后提交。UI只调用服务并显示结果，不自行解锁、扣费或写文件。

初始仅主战炮和轻型履带Lv.1。application_error校验已实现基础定义、拥有状态、现有LoadoutResolver承载规则。apply先验证，创建候选快照，保存成功后才替换内存；失败保持原配装。存档只写拥有等级与已应用配装，不保存试炼草稿或场景。

## 保存与恢复
路径user://equipment.json，version=1。验证未知ID、错误类型、非整数/超范围等级、未来版本、未拥有的已应用部件。非法数据拒绝；主档无效尝试.bak，双档损坏则阻止覆盖。写入.tmp并flush，复制有效主档到.bak，再rename替换；Windows不承诺绝对原子替换，备份用于恢复。当前首版没有历史schema迁移需求，未来版本需明确迁移。

## 机库流程
当前6个已实现部件显示稀有度、拥有/等级和能力待实现状态。选择只改草稿；锁定部件可隔离试炼，不可应用。撤销恢复已应用；退出至主页丢弃草稿，再进入读取存档；试炼往返保留预览，但不改装备。UI当前仍双行选择，完整32项分页与技能详情待下一批。
