# 113 机库关闭实时投影与柔和灯光

2026-10-16，桌面自动检查及实际渲染通过，用户观感及Android待验收。

## 目标与所属层

用户明确要求去掉机库预览阴影，并认可无实时投影的柔和展示灯光。仅调整HangarPreview独立显示世界，保留材质明暗、立体感和展示台；不修改训练场灯光或实战阴影。

## 接口与变更文件

- presentation/hangar_preview_style.gd：camera_far=12、shadow_opacity=.72、shadows_enabled=false，全部表现Resource参数。
- presentation/hangar_preview.gd：主光读取shadows_enabled；正交阴影模式与近景裁面保留供诊断，但最终关闭实时投影。
- content/presentation/hangar_preview.tres：主光.65、补光.30、轮廓光.43、环境光.24；远裁面12；shadows_enabled=false。
- tools/capture_hangar_113.gd：实际机库/十二组合正背面/960×640与滚动检查，同时断言每个预览Light3D均未启用阴影。
- tools/probe_hangar_shadow_112.gd：此前诊断对比脚本，试验参数不作为最终配置。

## 诊断与实际验收

原机库使用默认相机远裁面和较大的阴影偏移。试验中缩小范围改变阴影覆盖，过低偏移产生密集自阴影条纹，调整偏移后条纹改善，但投影仍硬。远裁面只是影响因素，不宣称它为全部观感问题的唯一原因。正交阴影范围行为参考Godot官方DirectionalLight3D文档：https://docs.godotengine.org/en/stable/classes/class_directionallight3d.html 。

最终按用户选择关闭投影，保留灯光对表面法线的明暗响应，不能把剩余面明暗称为投影仍未关闭。`capture_hangar_113.gd`十二组合、机库正背面、小窗口和滚动实拍PASS；预览灯光全部关闭阴影的断言通过，实际图像已审阅，车体与台面无实时投影，保留表面灯光明暗。`tools/check.mjs`完整检查30/30 PASS。

## 限制与下一步

无实时投影意味着没有精确的车身自遮挡和地面投影，属于用户确认的展示风格选择。Android显示效果与性能待真机。
