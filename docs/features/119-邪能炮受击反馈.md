# 119 邪能炮受击反馈

状态：实际渲染审阅通过；完整检查首轮29/30，失败项修复后专项通过。用户观感与Android待验收。

## 目标与问题

用户指出邪能大招缺少受击效果。前轮去掉金色通用爆点后，技能弹的通用命中特效被过滤，但没有补充真正造成伤害时的专用反馈。现在在实际伤害提交后显示暗红能量冲击/破裂碎屑，同时目标装甲短暂闪红；空放不显示目标受击。

## 所属层与接口

领域只补伤害来源元数据，不新增伤害：HitEvent增加ability_id，穿刺攻击写入breach；DamageResolver结果携带ability_id/projectile_id，方便每个被穿透目标独立反馈与去重。受保护、友方、旧生命或零实际伤害不会产生对应damage_applied结果。

表现监听已提交damage_applied；命中图使用既有生成红色序列帧并暗红调色，最长12tick。装甲覆盖材质按实例独立、8tick退去并恢复原覆盖材质，模型源材质只读。训练靶转发完整提交事件，保证暂停冻结和清理；死亡/重建/结束沿用TankView清理入口。
