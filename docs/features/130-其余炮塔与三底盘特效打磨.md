# 130 其余炮塔与三底盘特效打磨

状态：桌面33/33检查、132帧真实训练采集与正常镜头审阅通过。其他炮塔/底盘的最终用户观感及Android待验收。

## 目标与所属层

承接用户确认的129主炮样板，将短接触、独立运动、清楚退场的原则应用于其余三炮塔及三底盘。仅改presentation、表现Resource、验证工具和文档；battle/session/伤害、射程、装填、技能持续时间、碰撞及模型挂点不变。使用godot-gdscript与game-feel技能；无新增生图或复制参考项目素材。

## 行为与接口

- 速射机炮：普通/风暴枪口均为3tick短闪，普通命中5tick，实际连续开火形成节奏；风暴弹改为跟随权威方向的短圆钝亮迹，移除整张火舌弹图。持续风暴只留小型机械亮点，冷却双排气烟降低透明度。
- 散弹炮：5tick宽扇爆口，命中7tick；冲锋的两小团尘土沿已提交locked_yaw反向飞散，瞄准改变不会扭转尘土方向。
- 泡泡炮：准备/弹体/尾滴采用原创三色单颗水体shader；一次破裂为一个水花与三个独立小水滴，各自抛落。留场水面改为低填色、细边及少量不规则泡沫弧，严格留在原权威半径内，到最后退场段再淡出。
- 轻履带：只在已提交cruise装填状态激活时出现双侧短机械亮点，随车身已提交位置移动。去掉巡航速度箭头，避免误读为旧增速机制。
- 重履带：真实guarded事实触发一次车头接触闪和两道向外偏转的小火花；body_yaw决定方向，可视接触位置移到车头以免被车身遮住。重复事实共同去重，原贴地正面弧保留。
- 侦察轮式：主烟团与较小较淡的副烟丝使用不同图格，避免同图重复叠加；取消寿命中途强侵蚀，由区域剩余tick负责末段淡出，原减速范围与脱险加速不变。

新增toon_accent_group.gd统一负责小水滴/火花/尘土/装填亮点的确定性运动，每组最多3颗；位置按age/60解析计算，不作delta积分。组与接触共同到期/清理，受原事件预算约束。主炮129主体轮廓、弹道和碎片参数保持原值。
