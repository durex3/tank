# 013-已有坦克美术接入与中文机库

日期：2026-10-11。状态：实现、15项自动检查与桌面视觉检查完成；Android待验收。

## 目标与结果

将此前英文选项与小型灰盒预览机库改为中文整备车间：左侧三炮塔/三底盘卡片和属性，右侧大幅配装设定图、载重提示与试炼入口。九种组合精确匹配稳定ID，选择同步属性和训练配装。复用六张用户已有图，生成三张无推土铲的四轮侦察底盘图，原资产不覆盖。

默认展示透明PNG设定图；“查看装配模型”可切换原有基础3D预览，再切回图片。PNG不冒充可转向3D模型，战斗模型、镜头和灰盒地图本批未升级。

## 所属层与接口

- presentation/HangarArtCatalog：按武器/底盘ID返回设定图，与领域定义解耦。
- ui/theme/HangarCopy、HangarStyle：集中中文文案、字体、色彩和圆角样式。
- ui/widgets/HangarPartCard、HangarStatsPanel、HangarArtStage：独立选择卡、解析属性展示、图片/模型切换。
- ui/screens/HangarScreen：调用HangarSession.select，保留返回、训练与恢复选择接口；无战斗公式。
- 定义、伤害、冷却、承载解析与对局规则未修改。
