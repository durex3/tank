# 010-三类武器攻击与配装训练

状态：实现、12项Windows自动检查及Compatibility桌面视觉检查完成；Android待验收。

## 目标与分层
实现机关炮连续射击、散射炮五弹扇形，并让机库九种配装创建对应训练会话。battle只消费PlayerCommand，用独立攻击形状策略和统一冷却控制器；input负责松手/按住语义；loadout维护内容查找和属性解析；session在开局统一配置；app传递稳定ID与路由；ui显示解析结果，presentation沿用已接入贴图和部件场景。

本轮使用godot-gdscript、godot-physics、input-systems技能及Node REPL MCP执行本地Godot。未生成新美术，未覆盖原assets。

## 玩法与接口
- 主炮：120伤害，48tick冷却，松手单发。
- 机关炮：25伤害，10tick冷却（配置0.16秒按60Hz向上取整，实际约0.167秒），按住连射，松手不补发。触控需将右摇杆拖出死区。
- 散射炮：每颗32伤害、5颗、24度总扇形、60tick冷却；松手单发。偏移角为-12/-6/0/6/12度，所有弹丸从同一权威射口出发。
- WeaponDef.continuous_fire只读；WeaponController.poll新增continuous参数，默认保持原主炮接口。按住射击request_id=0，弹丸ID仍唯一。
- ShotPattern/SpreadShotPattern及WeaponPatterns只决定方向偏移，复用弹丸扫掠/批量伤害；没有复制坦克或伤害公式。
- ProjectileSystem.spawn_volley先检查整组预算，剩余4个位置时拒绝5弹组，不创建半组或命中。拒绝仍消耗该次武器冷却，并发布fire_rejected；成功仅发布一次weapon_fired，含pellet_count。
- MovementSession.configure_loadout只允许入树前调用。开局统一同步模拟武器、解析属性、部件ID、两个输入源模式。比赛中修改返回明确错误。
- 机库Train this loadout传稳定ID给app；app创建新训练并持有本次选择，Back返回机库恢复选择，不写磁盘存档。首页直接训练仍使用主炮/轻履带。
