# 005-灰盒坦克镜头与移动碰撞

日期：2026-10-11。状态：实现、自动测试及桌面渲染检查完成；Android真机待验收。

## 目标与所属层

落实T004：让004输入驱动独立物理坦克，实现加速/减速、掩体和边界碰撞、固定等距镜头及炮塔独立瞄准。尚无射击、伤害、Bot与对局赛制。

## 分层与公开接口

- core/planar_input.gd：to_world/map_command，接收水平镜头基向量，转换屏幕方向为世界XZ，不依赖Camera节点。
- battle/actors/tank_state.gd：每辆坦克独立位置、速度、炮塔与车身朝向。
- TankMotor.step：唯一物理速度所有者，以底盘加速度趋近目标速度，move_and_slide约束碰撞；玩法Y保持0。
- TankActor.configure/step：组合CharacterBody3D、半径0.55米圆柱碰撞与Motor；不读取Input、不创建外观。
- BattleSimulation.enqueue_command/step/clear_command：验证基础字段、epoch、sequence与tick窗口；6tick无输入则归零，按60Hz推进；输出snapshot_ready供表现消费。
- presentation/TankView：程序化灰盒模型，车身跟随速度，炮塔跟随aim_yaw，保留Muzzle视觉标记；不改权威状态。
- CameraRig：固定正交镜头，水平基映射和鼠标地面投影；调参存CameraTuning/content/camera/fixed_arena.tres。
- DesktopInputSource：InputMap动作，支持WASD/方向键；鼠标地面方向由会话注入。按键不进入战斗组件。
- session/MovementSession：会话生命周期、设备输入选择、镜头映射、模拟调度与表现订阅。
- session/graybox_arena.gd：临时32×24米灰盒地图组装，四边界、四掩体、网格，外观盒体和碰撞尺寸同源。
- ui/screens/movement_screen.gd/.tscn：固定16:9 SubViewport，其他比例信箱显示，触控预览和返回按钮。

## 其他变更文件

app/bootstrap.gd、ui/screens/project_home.gd：首页Drive tank prototype入口与返回路由。project.godot：具名移动动作。tools/check.mjs：新增移动测试和battle/input依赖守卫。tests/battle/movement_tests.gd与tools/capture_movement.gd：物理回归及实际截图。AGENTS.md与架构规则同步增加session层说明。

## 操作方法

Godot打开project.godot并F5 → Drive tank prototype。WASD/方向键移动，鼠标独立瞄准。Touch controls开关切换触控，左摇杆移动、右摇杆瞄准；桌面鼠标可模拟单指，手机可双指。技能和射击尚未执行。Back停止输入并销毁会话。

## 实际验收

node tools/check.mjs七项PASS：架构守卫、版本、导入、领域、输入、移动、启动。

移动回归运行真实Godot物理帧，覆盖：240tick连续移动、速度不超过6m/s、Y固定、边界不能穿越、内部掩体阻挡、加速度渐进、输入超时停车、旧epoch/重复序号/未来tick拒绝、镜头旋转映射、斜向幅度、炮塔独立方向、完整页面启动/退出、触控端到端驱动与取消后停车。首次方向键绑定测试发现左右键值错误，修正后完整重跑PASS。

实际Compatibility/NVIDIA桌面渲染截图artifacts/movement-prototype.png已检查：地图、四掩体、坦克和入口提示可见。镜头随后收紧至27米正交尺寸提高坦克可读性；桌面渲染不替代移动性能测试。测试主协程较长是按物理帧组织的固定场景验收，不作为运行脚本模式。

## 限制与下一步

本功能未实现射击/技能、Damageable、死亡、复活、碰撞软分离、地图导航和多人权威调度。当前单坦克模拟接口后续扩展entity_id队列；不宣称跨设备物理确定性。离线真正暂停在M2实现，本轮失焦会清输入并减速停止。

原型镜头固定全场，未实现跟随平滑；灰盒无新增图片或外部资产。Android安全区、导出预设、键鼠以外控制设备和10分钟触控手感仍待验收。下一编号006：主炮弹丸扫掠、伤害训练靶和事件反馈。
