## 公开接口

- TouchInputState.configure(regions)：移动、瞄准、技能三个逻辑坐标区域，改变布局时取消旧输入。
- press/drag/release：触点按下时绑定控件，直到释放不改归属；同控件拒绝第二个触点；忽略未归属拖动和非法坐标。
- sample(tick, epoch)：统一命令、递增sequence；移动归一化后量化int8；yaw零度指向-Z，正角朝+X。此轮为屏幕平面方向，下一步CameraRig做世界XZ映射。
- cancel_pending/set_enabled：清触点、连发与未采样请求；失焦、退后台、退出页面与禁用时调用。
- TouchInputSource.handle_event：仅接收ScreenTouch/ScreenDrag；canceled优先于pressed，鼠标事件不再重复生成攻击。
- TouchInputTuning及content/input/default_touch.tres：64逻辑像素半径、径向死区0.15、上拖超过2半径取消，资源只读。

## 行为边界

主炮模式松手发一次，死区点按沿最后有效瞄准方向；机炮模式拖出死区后held，松手不发单发。技能独立松手提交。上拖取消区以红色显示，移回可恢复预瞄。系统取消不能当松手。

本地sample消费请求一次；两个采样间快速多次松手仅保留最新意图，避免排队延迟开火。网络重发、100ms权威请求容错与去重后续由会话层实现。每个TouchInputState保持独立状态；共享调参Resource不写回。
