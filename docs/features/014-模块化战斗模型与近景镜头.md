# 014-模块化战斗模型与近景镜头

日期：2026-10-12。状态：实现、16项自动检查和桌面渲染验收通过；Android待验收。

## 目标与所属层

制作三炮塔、三底盘的真实3D部件，提供白色装甲、金色轮毂/炮口、履带、轮胎、观察镜和排气细节。presentation维护模型、镜头、环境饰面和血条；session在模拟提交后更新镜头；UI显示解析属性和已提交事件。原assets只读。

## 接口与变更

六个presentation/parts场景通过tools/build_tank_parts.mjs可重建，共享重复网格与材质。TurretSocket和Muzzle位置/朝向、角色碰撞与攻击策略保持原契约。TankPartCatalog九组合装配回归通过。模型为独立风格化制作，未声称达到设定图精细度。

新增presentation/ArenaDressing、WorldHealthBar；更新CameraRig、CameraTuning、fixed_arena.tres、TankHealthView、TrainingTargetView。场地地砖使用MultiMesh，掩体增加饰面，原32×24米碰撞布局不变。外围树木位于不可进入区域，无新增视觉碰撞。

镜头斜视正交尺寸14.5，偏移(14,19,16)，死区0.75米、指数跟随率8、8米以上切换、焦点边界±14/±10米。边界限制焦点，不承诺整个视野都在场内；场外显示背景。暂停停止跟随，屏幕投影依旧用于瞄准。近景会裁掉远处目标，需移动观察。

更新movement_screen、DuelPanel训练入口，新增BattleCopy集中训练HUD文案，复用HangarStyle。玩家/Bot有青/红阵营环及血条；暂停和结算页面尚未整体中文化。
