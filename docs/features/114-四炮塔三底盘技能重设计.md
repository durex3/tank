# 114 四炮塔三底盘技能重设计

状态：桌面自动检查与实战渲染审阅通过；用户观感、Android与真人平衡待验收。

## 目标与确认

按2026-10-16用户确认直接开发：大招属于炮塔，底盘保持被动，通过射程、移动装填、正面承伤和脱险形成配装优势与代价。速射机炮火力风暴保留。用户随后反馈主炮弹丸丑、大招缺少邪恶红色能量感，因此本轮同步重做主炮表现。未扩展新部件或3v3。

## 当前规则与层级

- 主战炮：27tick蓄力后瞬时直线穿刺闪电，16米，最多3敌240/144/86伤害；墙体截断，蓄力移速60%。无自动追踪、无连锁；普通弹保留原数值。
- 速射机炮：保持180tick火力风暴、3tick间隔、当前普通伤害60%、90tick红温，松手停火。
- 短管散弹：15tick准备后沿请求时的瞄准方向冲锋，最多4.5米、12米/秒；敌方接触80伤害并停止，墙体停止，无无敌，不重置普攻冷却。实际位移仍只由TankMotor提交。
- 泡泡炮普通弹：真实分段抛物线扫掠，命中55基础伤害与15%减速60tick；4发、39tick间隔、84tick填弹及原成长保持。鼠标地面落点决定距离，触控瞄准杆力度决定距离。
- 泡泡炮大招：21tick准备，冻结落点，预留1个弹丸预算；36tick抛投后生成半径2.2米泡池，存活240tick，每30tick对区域内敌人造成20伤害，区内速度65%。离区停止区域减速与伤害，多个减速取最强；区域伤害不享受直接弹丸护甲、不回充能量。死亡、换生命、退出清理。
- 轻履带行进装填：自主有效移动速度至少0.6米/秒，每4tick额外推进1tick普通射击间隔/弹匣装填。停止、顶墙、强制位移及技能阶段不触发；不增加最高速度，不缩短红温或技能间隔。
- 重履带正面装甲：移动也可减免正面120度直接弹丸30%伤害；侧后、冲撞、区域持续伤害不减。
- 侦察轮式脱险烟幕：保持056规则，受非致死伤害后下一tick开始90tick加速25%，烟幕150tick、敌人速度65%、冷却600tick。

所有数值属于只读定义，运行状态按实体/生命独立。旧稳定ID（breach/shock/bubble、cruise等）保留兼容存档与接口，名称不再代表旧机制。旧ShockwaveAttack仅留作既有击退基础设施回归，当前散弹技能不调用它。

- `battle/projectiles/`：普通泡泡弧线扫掠，主炮大招一次扫掠并携带终点事件；技能区域查询独立于表现。
- `battle/actors/`：TankMotor合成强制冲锋；TankActor记录已提交瞄准距离。
- `definitions/basic_ability_rules.gd`、`bubble_rules.gd`、`weapon_def.gd`：初版数值配置。
- `presentation/`：按提交tick播放翻页动画、闪电与能量雾、散弹冲锋预警/尘土、泡池及普通落点圈；CombatView在同ID由抛投切换为区域时重建表现。

- `content/parts/catalog.tres`与`ui/widgets/ability_hud.gd`：同步技能与被动说明。
- `tests/battle/{ability_tests,bubble_tests}.gd`及`tests/presentation/ability_vfx_tests.gd`：更新新契约并保留不受影响的成长、能量、风暴、生命、暂停与旧击退基础测试。

## 美术来源

`assets/generated/vfx/skills-v2/provenance.json`记录OpenAI imagegen来源、提示词和处理方法。透明原图保留，16张独立256px帧用于红色能量、装甲火花、尘土与装填流光。读取原图并人工审阅后切分，独立留边防采样串块。PNG只用于表现，不代替坦克模型。原有3D模型与权威挂点未改。

先尝试Pillow处理失败（环境无Pillow，候选Python路径亦不可用），最终使用Godot Image API成功生成；没有伪报失败步骤成功。
