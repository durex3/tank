# 074 规则轮组与闭合履带动画

状态：桌面自动回归通过；用户连续观感、Android真机待验收。

## 目标与所属层
保留Rodin车身与短炮管，替换无法可靠拆轮的轻型履带。新轮组为真实程序化3D：左右各三完整车轮、闭合带体、各48片循环履带片。仅presentation层，未改碰撞、权威射口、数值或成长。

## 接口与文件
- `TrackRigStyle` / `content/presentation/track_rig.tres`：米制尺寸、颜色与履带片数量，只读配置。
- `TrackRig.present_travel(Vector2)`：左右累计行程，完整轮旋转与MultiMesh履带片沿闭合路径移动；每实例独立。`cleat_pose`保留CPU侧姿态供headless验证，因为无渲染后端的MultiMesh读回不能用于几何断言。
- `TankTracks.sample(position, yaw, tick)`：提交后位移与转角驱动；空转输入无位移不播放，重复tick忽略，瞬移/死亡/换件清理，暂停由会话冻结tick。
- `tools/derive_track_rig_hull.py` → `assets/derived/track-rig-v1/hull.glb`：原BANG网格0另存，原导入资产只读；轮组由代码构建，不声称Rodin生成独立轮组成功。
- `presentation/parts/track_rig_v1/light_tracks.tscn`、`tank_part_catalog.gd`：仅替换light_tracks，挂点不变。
- `hangar_part_art_catalog.gd`、`tools/capture_track_icons.gd`：卡片使用新底盘实际渲染。
- `tests/presentation/tank_motion_tests.gd`：前后行驶、转向差速、静止、重复tick、实例隔离、死亡/瞬移/换件与实际会话暂停回归。
