# 029-载重规则与升级训练接入

日期：2026-10-12。

目标：按用户要求采用第15节载重提案：超重1允许装配且速度降低20%；超重2及以上禁止应用。

所属层与接口：Definitions/Content存只读LoadoutRules；LoadoutResolver统一resolve/can_save。Profile、EquipmentService和MovementSession继续复用解析与校验；UI只显示结果。

规则：content/rules/loadout.tres配置maximum_overload=1、speed_penalty_per_overload=0.2、minimum_speed_ratio=0.6。最低速度比例保留60%用于非法草稿预览，不能使非法配装合法。已装备升级沿用候选校验、保存后提交，若升级使已应用组合非法则拒绝扣费及提交。六种基础部件成长表不改，7级重量/承载断点保持。

变更文件：definitions/loadout_rules.gd、content/rules/loadout.tres、loadout/loadout_resolver.gd、ui/widgets/hangar_art_stage.gd、ui/widgets/hangar_upgrade_dialog.gd、ui/screens/hangar_screen.gd、tests/domain/run_tests.gd、tests/domain/equipment_growth_tests.gd、tests/presentation/hangar_growth_tests.gd、tools/capture_hangar_workbench.gd与规则/计划/索引/交接文档。

表现：机库超重显示实际降速比例，非法组合禁止试炼；升级弹窗重量、移速、超重独立红绿对比，并展示现行规则。应用和训练开局仍校验领域资格。升级警告只在超重或移速进一步恶化时显示，不因原有超重而显示无变化警告。

验收命令：GODOT_BIN=/Applications/Godot.app/Contents/MacOS/Godot node tools/check.mjs；Godot tools/capture_hangar_workbench.gd。
