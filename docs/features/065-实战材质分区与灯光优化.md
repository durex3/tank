# 065 实战材质分区与灯光优化

日期：2026-10-13。状态：桌面实现与验收通过，Android待验收。

## 目标、层与接口

以主战炮＋轻履带为样板，改善实战白装甲杂色、机械层次与地面干扰。属于presentation、表现Resource及session灯光组装；TankSurfacePolish.apply只创建实例材质覆盖，原资产与共享网格材质只读。无领域、碰撞、数值或射口改动，未改变镜头与输入投影。

## 变更文件

- presentation/shaders/clean_armor.gdshader：亮且低饱和的装甲区域向统一象牙白柔和归一，保留暗接缝、金色与绿色光学细节；降低法线杂波。保留原PBR贴图，无贴图时使用显式开关与金色区域材质估计，不伪称新增真实PBR贴图。
- presentation/tank_surface_style.gd、content/presentation/tank_surface.tres：清理强度0.55、法线强度0.40及装甲色，配置只读。
- presentation/tank_surface_polish.gd、presentation/tank_view.gd：仅处理cannon/light_tracks；每实例独立ShaderMaterial，换件与PREDELETE前清理覆盖，原纹理直接复用。
- presentation/training_view_style.gd、content/presentation/training_view.tres：主光0.82、环境0.34、主光方向/暖色、阴影距离24米/blur 2、低对比中性色地砖。
- session/movement_session.gd、presentation/arena_dressing.gd、ui/screens/movement_screen.gd：统一消费训练表现Resource；灯光、地砖与离屏参数来源一致。
- tests/presentation/tank_parts_tests.gd：补实例材质隔离、原材质/贴图不变回归。
- docs/development-plan.md、docs/features/README.md同步。
