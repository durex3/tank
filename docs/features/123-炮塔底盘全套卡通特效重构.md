## 目标与层级

按 docs/art/132-卡通特效全流程生图与接入手册.md 重构四炮塔、三底盘全部表现，包括大招。仅 presentation、表现资源与离线素材工具变更；battle、session、TankMotor、伤害、权威范围、发射与技能时序未修改。PNG 为数据纹理，不是三维部件。

## 素材与接口

- 内置 image_gen 生成八族四格灰度源图，保存在 assets/generated/vfx/toon-fx-v1/source/。实际提示词、工具、来源路径见 prompts.json / provenance.json，无外部参考图。
- tools/prepare_toon_fx_131.py 按手册原样写入，量化 R 三阶、生成固定种子 G 侵蚀、保留 A；输出32张512单格及8张1024图集。生成源图实际尺寸由工具决定，后处理统一尺寸；源图不覆盖。
- presentation/shaders/toon_fx.gdshader 与 ToonFxMaterials：共享着色器、五份独立渐变资源，每个实例复制材质。各格为不同形状，不按动画帧轮播。R/G 不使用 source_color，颜色渐变使用 source_color。
- 地面提示为原生平面几何，ToonGroundGeometry 绘制有宽度的断弧/箭头，无竖直挤出面。没有重新使用被否决的 combat-fx-v2 地面图。

- presentation/ability_sprite_effects.gd：主炮/速射/散射枪口、普攻命中、烟幕、红温烟；去掉旧蓄力重复层，生命使用提交tick。

- presentation/ability_effects.gd / toon_ground_geometry.gd：正面装甲断弧、逃生/装填箭头、贯穿蓄力方向、冲锋方向、红温/风暴剩余时长环、烟区边界、泡泡落点预览。
- presentation/bubble_visual.gd / bubble_bursts.gd：普通泡泡、抛投大招、落地水域、水花；落地区域固定水平，不朝相机竖立；不更改弹丸数据。

- content/presentation/toon_fx_{warm,metal,water,dust,guard}.tres 与 presentation/toon_fx_materials.gd。
- tests/test_toon_fx_123.gd：材质实例隔离、同tick冻结、大招所属实体死亡清理回归；已写入，未运行。
