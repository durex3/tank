用户接受参考项目第一版的卡通机械方向，要求继续尝试。沿用create-game-assets及godot-gdscript流程，仅修改表现层、表现Resource与离线工具。主炮由134圆壳改为两侧分片斜装甲包住深灰核心，增加分段炮管、套筒、散热口；轻履带固定车壳使用切面甲板、独立挡泥板和简洁前后机械细节。象牙白主装甲、深灰结构与黄色炮口形成明暗层级。
