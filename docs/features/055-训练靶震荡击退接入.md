# 055-训练靶震荡击退接入

日期：2026-10-13。状态：桌面23项自动检查及实际渲染审阅通过；Android与真人连续试玩待验收。

目标：解决用户试炼场中散射大招有伤害却看不到训练靶击退的问题。048末尾原有限制为固定/巡逻靶不参与击退，本次补齐，不调整150伤害、1.2米最大位移、12tick持续或扇形规则。

所属层：battle。接口：BattleSimulation在DamageResolver整批结算之后，以最终HP和生命ID筛选训练靶，汇总该tick已提交push并限长，调用TrainingTarget.commit_push(displacement,duration_ticks)。下一个模拟tick的step_motion执行；不从UI或表现驱动位移。

实现：AnimatableBody3D使用move_and_collide逐tick移动，碰撞掩码包含世界和坦克；实际位移累积为巡逻路线偏移，结束后不会跳回旧路径。击退期间暂停自主巡逻，相位不推进；结束沿偏移后的路线继续。reset_motion清位移与偏移，重建恢复出生位置；死亡不推进，暂停/结算不调用step，冻结待提交位移。TankActor继续由TankMotor唯一合成速度，两类身体不混用物理控制器。

变更文件：battle/actors/training_target.gd、battle/battle_simulation.gd、tests/battle/ability_tests.gd、tools/capture_abilities.gd；docs/development-plan.md、docs/features/README.md及本记录。原美术、数值资源和存档未改。
