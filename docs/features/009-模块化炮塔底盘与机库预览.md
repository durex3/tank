# 009-模块化炮塔底盘与机库预览

状态：实现、11项Windows自动检查及Compatibility桌面视觉检查完成；Android待验收。

## 目标与所属层
将原先TankView内直接创建的几何体拆为六个可独立编辑和替换的原生Godot部件场景，提供九种组合机库预览。presentation负责外观装配，session/HangarSession持有临时预览选择并调用LoadoutResolver；ui显示解析结果；app只路由页面。战斗定义不依赖模型，机库不创建BattleSimulation。

## 接口
TankPartCatalog维护稳定玩法ID到PackedScene的映射，validate_part拒绝缺失/偏移/旋转挂点、非单位根变换及碰撞节点。TankView.configure_parts(weapon_id,chassis_id)先验证新部件再替换，错误返回字符串且保留旧模型。HullMount与TurretMount为同级节点，各自响应body_yaw/aim_yaw；muzzle_transform提供可视射口变换，不作为伤害裁决来源。

底盘TurretSocket=(0,0.76,0)，炮塔Muzzle=(0,0.02,-1.05)，组合射口=(0,0.78,-1.05)。九种组合均与现有权威射口匹配。契约先记录于docs/art/009-部件接口约定.md。

## 变更文件
- presentation/parts/{light_tracks,scout_wheels,heavy_tracks,cannon,autocannon,scatter}.tscn：原创基础低多边形样件，无战斗脚本和碰撞；轮式采用圆柱轮，履带与炮塔通过轮廓/颜色区分。
- presentation/tank_part_catalog.gd、tank_view.gd、hangar_preview.gd：部件验证、装配、独立预览世界和展台。
- session/hangar_session.gd：临时选择和解析属性，非法索引不修改原草稿。
- ui/screens/hangar_screen.gd/.tscn：炮塔/底盘选择，HP、速度、伤害、弹丸数、冷却、重量/容量/超载展示；容器布局、默认焦点、Esc返回。
- ui/screens/project_home.gd、app/bootstrap.gd：首页机库入口与页面销毁/返回路由。
- tests/presentation/tank_parts_tests.gd、tools/check.mjs、tools/capture_hangar.gd：自动回归与实际渲染证据。
