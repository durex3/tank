2026-10-15。下载、独立预览及离线机库试装完成；正式模型接入待验收。

## 资源与接口

下载两个原始PBR GLB至assets/imported/modular-sample-v1，原始文件不改写。任务和永久链接见assets/generated/modular-sample-v1/rodin-jobs.json；SHA256、原始外廓和面数见inspection.json。每件单一网格、20000三角形，两件共40000三角形；单网格不能证明车轮或炮管已经独立。

tools/prepare_modular_preview.py可重建独立包装，输出presentation/parts/modular_sample_v1。外层根保持identity、Muzzle=(0,0.02,-1.05)、TurretSocket=(0,0.76,0)，通过TankPartCatalog.validate_part验证。只对Geometry做等比缩放；炮塔旋转180度使枪口朝-Z，炮座位置根据原始渲染估计，仅供预览，不作为权威射口或已验收装配数据。

预览读取现有content/presentation/part_size.tres的同类宽度；高度与总长没有通过080统一外廓要求。原始T02约1.115×0.956×1.892，C03约1.626×0.978×1.893。等比对齐现有宽度后，炮塔明显比现标准高，故不修改TankPartCatalog生产映射，避免把候选尺寸或缺失动画当作正式替换。

## 使用

运行tools/open_modular_preview.ps1，或在Godot打开并运行presentation/previews/modular_sample_preview.tscn。左键拖动旋转、空格新旧切换、Esc退出。失焦清理拖动。场景复用HangarPreview的灯光、材质环境和平台，不创建战斗会话，不操作用户存档。

tools/capture_modular_assembly.gd另外在真实机库页面离线注入候选生成截图，使用专用测试存档；注入只存在于拍摄工具。正常主页/机库/训练不会显示候选，现有卡片仍为原资源。
