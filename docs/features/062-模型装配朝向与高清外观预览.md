# 062 模型装配朝向与高清外观预览

日期：2026-10-13。桌面实现与验收通过，Android待验收。

## 目标、所属层与接口

响应用户反馈模型不清晰及装配怪异，修正导入轻型履带前向，改善机库取景和细节可读性，整理剩余已就绪部件参考图。仅presentation/UI/工具与表现配置；稳定ID、原资源、碰撞、权威射口和数值保持不变。

## 变更文件与实现

- presentation/parts/tripo_v1/light_tracks.tscn：Visual绕Y转180度，将生成底盘的+Z车头统一为项目-Z；之前底盘车头和炮管相反，是060接入时漏校准的错误。
- ui/widgets/hangar_art_stage.gd：用TextureRect显示SubViewportTexture，显示尺寸变化时显式设置离屏像素尺寸；避免仅依赖3D scaling参数，确保Compatibility也实际以2倍宽高渲染后缩小展示。保留鼠标/触摸旋转和静态设计回退。
- presentation/hangar_preview_style.gd、content/presentation/hangar_preview.tres：2倍宽高采样，最大边2048，4x MSAA；camera_size 2.9→2.5；主/补/轮廓/环境光改为0.85/0.22/0.32/0.24，减少白装甲过亮。只影响机库，非训练性能配置。
- tests/presentation/hangar_art_tests.gd：对三种窗口尺寸检查实际离屏像素尺寸及上限，防止高清设置只有配置无实际作用。
- tools/export_part_references.gd：增加泡泡炮导出。artifacts/model-generation-references包含当前速射机炮、短管散射炮、泡泡炮、重型履带、侦察轮式图及来源/导出说明，同名zip便于用户批量获取。全部复用现有卡片图，无AI重绘；图集裁图分辨率有限，未伪称高清源图。

## 限制与下一步

2倍宽高渲染最多为原区域4倍像素，且有2048边长上限；机库GPU成本与Android热稳定仍需真机测量。原始2K贴图与生成几何的细节上限不变，不声称获得4K源细节。其他已就绪部件继续使用旧程序化真实模型，因此可以旋转；用户生成新模型后逐件替换。泡泡炮参考图来自原图集，透明罐生成结果需额外核对材质。下一编号063。
