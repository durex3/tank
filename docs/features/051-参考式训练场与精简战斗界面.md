# 051-参考式训练场与精简战斗界面

日期：2026-10-12。状态：桌面22项完整检查及实际截图审阅通过；Android待验收。

目标：按用户提供的训练场参考图，采用明亮暖灰地砖、训练坦克、清楚血条与四角HUD，减少调试面板遮挡。依赖042—050已有能力与清晰度配置；不扩展新武器、3v3或收益。

所属层与接口：TrainingHud只发返回/暂停/触控切换/对练请求；MovementScreen组装并把事件接入既有Session。AbilityHud只消费ability_state，独立被动卡和大招卡由页面锚定。TrainingTouchOverlay只绘制TouchInputState，输入仍走既有采样接口。TrainingTargetView通过TankPartCatalog装配模型，TrainingTarget继续持有权威碰撞、血量和移动。CameraTuning.focus_offset为只读表现取景偏移，CameraRig仍跟随提交位置，输入沿投影映射。

实现：暖灰地砖、木箱式掩体外观、边墙栏杆与花槽；出生区细线标记，避免覆盖技能范围。三个靶使用轻履带/轮式/重履带模型与红环，标记轻/中/重型训练靶，原350/670/1445血量和移动/重建保持不变。模型按原1.3米靶体占地缩放至0.65，属于训练模型而非正式配装属性。玩家/对手中文血条，当前HP置于条内。左上矢量导航与统计入口、右上训练操作、左下被动、右下大招；统计默认收起。触控模式独立图层显示摇杆，大招卡上移避让，按钮隐藏Q快捷键提示。镜头尺寸13.2与朝训练区域的焦点偏移，让三靶进入默认画面；保留1.5倍超采样/4×MSAA。

变更文件：ui/widgets/training_hud.gd、training_toolbar_icon.gd、training_touch_overlay.gd、ability_hud.gd；ui/screens/movement_screen.gd、ui/theme/battle_copy.gd；presentation/training_target_view.gd、tank_health_view.gd、world_health_bar.gd、training_view_style.gd、arena_dressing.gd、camera_rig.gd；session/movement_session.gd、graybox_arena.gd；definitions/camera_tuning.gd、content/camera/fixed_arena.tres；tests/presentation/battle_visual_tests.gd、tools/capture_training_redesign.gd；开发计划、功能索引、交接与本记录。
