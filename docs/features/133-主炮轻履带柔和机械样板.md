# 133 主炮轻履带柔和机械样板

状态：主炮＋轻履带样板已接机库、训练及对应卡片；桌面完整检查与实际渲染见下。最终用户观感和Android待验收，尚未推广其他部件。

## 目标、层级与接口

用户确认参考MiniTanks截图与本地资源，先统一主炮/轻履带的大体块、柔和材质及模型卡片。使用create-game-assets、godot-gdscript及godot-shaders工作流。仅表现、表现Resource、离线Blender工具和验证；不改battle/session/成长/存档/权威碰撞或规则。

当前样板映射presentation/parts/soft_workshop_v1，105/108/109原GLB/blend/包装与卡片保留。炮口Muzzle=(0,.02,-1.05)、TurretSocket=(0,.76,0)、根identity和part_size.tres外廓均不变。后坐、可视射口和轮带运动沿用既有提交事件/状态。

## 来源与制作

- 本机Blender 5.2.2 CLI运行tools/build_soft_workshop_133.py，原创连续装甲壳、宽倒角、内嵌侧通风槽、厚炮口及较安静的轻履带上甲板；没有调用已断开的Blender MCP，也没有直接复制参考模型。
- 复用本项目105脚本的基本几何构建函数，新造型独立另存。均为真实GLB，非PNG或贴图冒充模型。源文件source_art/soft-workshop-v1/soft_workshop.blend按整车装配摆放，导出时恢复独立模块原点。
- 炮塔8648三角形、11个导出材质图元；底盘固定车壳13276三角形、6个图元。轻履带圆轮、闭环带体和循环履带片继续使用既有TrackRig，不能称为重新Blender制作的整套轮带。
- 每个独立部件以12条半球射线烘焙局部遮蔽至顶点色，实测GLB炮塔11/11、车壳6/6图元保留COLOR_0。无新增2K贴图。
- 参考仅只读分析：assets/shaders/tank_soft_plastic.gdshader的柔和受光、局部遮蔽和曝光控制思路；porcelain_workshop/H04_walking.tscn的装甲/结构/橡胶材质区分；独立porcelain_workshop/icons和part_icon.gdshader。上述存在不证明截图使用了某一具体网格，未复制其代码或素材。

## 文件与表现

- tools/build_soft_workshop_133.py、assets/derived/soft-workshop-v1、source_art/soft-workshop-v1：可复建原创模型与来源记录。
- tools/integrate_soft_workshop_133.gd、presentation/parts/soft_workshop_v1：GLB轻量包装、复用原TrackRig参数，并先断言完整统一外廓。
- presentation/soft_workshop_finish.gd、shaders/soft_workshop.gdshader、definitions/soft_workshop_style.gd、content/presentation/soft_workshop.tres：原创单pass柔和受光、顶点遮蔽、上下明暗、适量柔高光。只给显式标记的两件样板应用，每个实例材质独立，不修改共享导入材质。
- presentation/tank_surface_polish.gd：按样板元数据分流；清理时保留原网格材料并恢复轮带MultiMesh材质。
- presentation/tank_part_catalog.gd：仅主炮与轻履带切到样板；其他炮塔/底盘保持当前生产版本。
- assets/derived/soft-workshop-cards-v1、presentation/hangar_part_art_catalog.gd：两张512透明PNG由同一真实模型/同一材质渲染，固定朝向/摄影；角点alpha=0和主体占位由Godot Image断言。
- tests/presentation/tank_parts_tests.gd：新增样板材质实例隔离、共享源不变及遮蔽顶点色导入回归；原十二组合、尺寸、圆轮、后坐与权威射口验证保留。
- tools/capture_soft_workshop_133.gd：三角度新旧对照和两张透明模型卡片。
- tools/capture_soft_production_133.gd：十二组合正反面及真实机库/旋转/960×640缩放，独立fixture存档。
- tools/capture_soft_training_133.gd：真实80tick移动与开火、轮带和后坐采集，不修改用户存档。

## 实际问题与修正

1. 首次Blender导出提示材质节点未使用顶点色，默认不输出COLOR_0；显式ACTIVE/all_vertex_colors后重新导出，逐图元核对通过。
2. 第一轮新旧渲染样板偏灰，原创light函数重复乘反照率；修正受光并回调独立样板参数，实际机库与正常实战回看。
3. 连续外壳遮住侧面通风细节，改为真实浅槽布尔切口，重新烘焙与导出，没有用贴面穿插补救。
4. 卡片首次继承机库不透明背景；改为透明视口清屏，并实际检查角点alpha和主体宽度。环境没有Pillow，使用Godot Image验收，无需新增依赖。
5. 初始对照第三行超出720高窗口，改成三行各240px，最终完整三角度可见。
