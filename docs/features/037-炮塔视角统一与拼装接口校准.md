# 037-炮塔视角统一与拼装接口校准

日期：2026-10-12。状态：桌面验收通过，Android待验收。

目标：改善036遗留的炮管方向与车身透视差异。保持已有三炮塔身份、白瓷棱角装甲/深机械/金边/绿光配色，保留三底盘原图与3×3独立拼装。

所属层与接口：presentation/HangarPartArtCatalog.texture按稳定ID返回隔离AtlasTexture；前三炮塔改用512透明版本图，卡片与HangarArtCatalog复用同源。HangarCompositionStyle按炮塔记录安装点与底座下沿遮罩，缩放跨底盘保持420宽。领域、载重、武器、真实3D模型不变。

变更文件：assets/generated/parts/aligned-v2三张PNG、导入设置、sources原生成图与provenance.json；presentation/hangar_part_art_catalog.gd、hangar_art_catalog.gd、hangar_composition_style.gd；tools/normalize_hangar_turrets.gd；开发计划、交接、功能索引与美术契约增补。

制作：使用内置image_gen逐个编辑三种炮塔，原卡片作为造型基准，整车九宫格作为视角参考，增加俯视并让炮管投影朝左下。归一化工具按alpha>=0.5主体边界加4像素测量，最长边480、512透明画布、Lanczos缩放，不改原文件。原生成图置sources/.gdignore，不导入运行资源。炮塔安装点cannon(0.57,0.89)、autocannon(0.62,0.83)、scatter(0.56,0.79)，下沿分别0.93/0.86/0.82；保留036接触阴影。

失败与迭代：散射炮首张带灰金光晕；一次背景提取仍保留光晕，均拒绝接入，最终重新用原卡片和新主战炮视角参考生成，实际确认无明显光晕。完整提示词、参考和工具输出位置保存在provenance.json。初次Python像素审计因PIL未安装失败，改用已有Godot工具完成；源图原处导入时离线Image加载有导出警告，后移动至忽略目录，运行代码只preload正式PNG。

验收：Godot --headless --path . --script tools/normalize_hangar_turrets.gd PASS；Godot --path . --script tools/capture_hangar_composition.gd PASS。已审阅完整机库卡片和九组合实际Compatibility截图，炮管、天线与车体未裁切，切换复用底盘和炮塔源图。修改前对照为artifacts/hangar-composition-gallery-before-037.png，调整后为hangar-composition-gallery.png。完整tools/check.mjs：21/21 PASS；git diff --check：PASS。

限制：图片是静态展示，不是3D；仍有轻微局部透视差异，未扩展未设计部件。真实模型精细度和Android验收待后续。下一编号038。
