# 110 泡泡炮紧凑喷头修订

2026-10-16。桌面检查与实际渲染通过；用户观感、Android待验收。

## 目标、所属层与接口

用户明确否决109裸露长支架和悬空喷环。本轮仅修改表现资源：保留圆顶压力舱与青色压力窗，将前部改成连续包覆、圆润扩口的一体喷头。无外露长杆，不恢复短管炮的楔形装甲。采用既有godot-nodes-scenes接入流程，通过Blender MCP建模导出。

统一外廓仍为1.038×.594×1.708米，Muzzle与RecoilPivot/VisualMuzzle接口保持；玩法、伤害、输入不变。109及105/108原资源保留，新资源派生另存。

## 变更与重建

- tools/build_bubble_110.py：读取109造型辅助函数及压力舱构造，独立新建喷头、检查闭合网格、按材质/运动节点合批。最终7124三角面，16个源网格、7个导出网格。
- source_art/bubble-compact-v1/bubble_compact.blend：可编辑源。
- assets/derived/bubble-compact-v1：GLB、几何统计、来源清单。
- tools/integrate_bubble_110.gd与presentation/parts/bubble_compact_v1/bubble_cannon.tscn：验证并包装新模型；TankPartCatalog仅替换泡泡炮映射。
- tools/capture_bubble_card_110.gd、assets/derived/bubble-compact-cards-v1与HangarPartArtCatalog：独立新卡片。
- tools/capture_hangar_110.gd、capture_training_110.gd：十二组合、机库、训练证据，输出artifacts/110-*。

重建顺序：Blender运行build_bubble_110.py → Godot --headless --editor --import → --headless --script tools/integrate_bubble_110.gd → 有窗口运行capture_bubble_card_110.gd → 再import → 运行机库与训练实拍。
