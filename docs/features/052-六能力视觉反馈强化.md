# 052-六能力视觉反馈强化

日期：2026-10-12。状态：桌面23项完整检查与实际截图审阅通过；Android待验收。

目标：强化重炮力量感、烟幕体积、装甲真实格挡反馈，并让巡航/风暴/震荡的动作形状更易区分。依赖042—051；本轮只改表现，不改技能数值。

所属层与接口：Presentation消费既有ability_started/ability_state/ability_fired/ability_zones、weapon_fired、projectile_hit与damage_applied事实。AbilityEffectStyle持表现尺寸/时长/数量上限。只有guarded事实产生格挡提示；动画按提交tick老化，不使用TIME/全局时间缩放。权威碰撞、射口、伤害、能量与冷却不变。CombatView仅读取ProjectileState决定核心/拖尾朝向，不移动领域弹丸。

实现：

- 破阵重炮：炮口聚能贴图、收束刻度、淡色瞄准线；发射用白亮核心/金色锥形拖尾，保留阵营颜色。修正非零朝向时旧拉伸弹视觉旋转符号。
- 脱险烟幕：每区域最多三层云团，轻微扩张/上升与末段淡出，保留真实半径边界和坦克轮廓；去掉旧空中圆环。
- 迎击装甲：分段前向屏障；实际减伤后18tick亮起并显示30tick“正面格挡”，普通受伤不提示。
- 巡航推进：加长双推进束，箭头按tick滚动。
- 火力风暴：强化期间更大的枪焰，热量环与排热线；散热阶段改冷灰环。ability_started使强化第一发即使用正确贴图规格。
- 震荡清场：复用尘浪贴图，通过空间Shader裁切到真实70度扇形及4.5米圆域内，缓出扩张最大不超过原平面；修复程序波纹此前只绘制玩家源的问题。

变更文件：definitions/ability_effect_style.gd；presentation/ability_effects.gd、ability_sprite_effects.gd、combat_view.gd、shaders/shock_sector.gdshader；tests/presentation/ability_vfx_tests.gd；tools/check.mjs、capture_abilities.gd；美术接入规范、开发计划、功能索引、交接及本记录。

美术来源与预算：复用049生图贴图及原提示词/来源，不覆盖图像资产，无新增生图。最多48个瞬时精灵/扇形平面、48层烟雾、8条格挡提示；当前双车会话最多2个聚能核心。烟层受全局上限约束，包括非整除预算与区域顺序变化。枪焰/核心朝镜头偏移0.14米只解决模型遮挡，不改变权威射口。格挡提示30tick，扇形尘浪18tick，烟区时间仍取BasicAbilityRules。
