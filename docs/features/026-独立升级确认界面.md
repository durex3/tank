# 026-独立升级确认界面

日期：2026-10-12。

目标：升级前单独弹出确认界面，告知数值变化，确认后才扣费保存。

所属层：UI。HangarProgressPanel负责确认呈现，继续调用EquipmentService.upgrade(id, expected_level)，不新增成长或扣费公式。

接口：升级入口先打开ConfirmationDialog；确认使用打开时捕获的部件ID和等级。取消不提交。未拥有部件仍走原解锁操作。详情入口与右侧升级入口共用此流程。

变更文件：ui/widgets/hangar_progress_panel.gd、tests/presentation/hangar_growth_tests.gd、tools/capture_hangar_workbench.gd及计划/索引/交接。

呈现：独立背景遮罩、部件名称与等级、伤害或耐久前后值、重量或承载前后值、当前组合升级后载重与移速变化、技能不变说明、金币费用和余额、取消/确认升级。
