# 098 样板炮塔比例与安装高度修正

2026-10-15。样板比例已调整并审阅；用户观感、全家族统一外廓和正式模型待验收。

目标：修复097试装炮塔过大、过高的问题。所属层：presentation独立美术预览，不改变生产模型目录或领域。

以097炮塔为基准整体等比缩小22%（0.78），安装偏移由0.18降到0.12米。底盘及摄影参数保持不变，避免用镜头调整掩盖真实比例。参数记录在content/presentation/modular_sample_preview.tres，仅为样板审阅修正系数；生产唯一尺寸来源part_size.tres及080同类宽高总长一致要求不变，当前不声明七件已统一。

实测候选外廓（宽、高、含炮口总长）：炮塔1.0296×0.882728×1.747688米；底盘1.65×0.992302×1.920692米。宽度比62.4%，炮塔高度和总长小于底盘。三个轴使用同一缩放系数；炮口、轮胎未非等比拉伸。权威Muzzle、TurretSocket、根变换不变。

接口与文件：新增modular_sample_style.gd与modular_sample_preview.tres；modular_candidate_part.gd读取样板修正资源；modular_sample_preview.gd标注比例修正版；prepare_modular_preview.py同步来源说明；capture_modular_assembly.gd增加实际源外廓缩放后的相对体积边界断言。原GLB未修改。

验收：capture_modular_assembly.gd通过，包含等比缩放、新旧切换、炮塔宽度比不超过65%、高度/总长小于底盘。四角度及机库截图已生成；正背面与机库图已人工审阅，底盘支撑关系改善，未见明显悬空。调整前截图另存artifacts/modular-assembly-before-098.png及modular-hangar-before-098.png。完整检查待执行。

限制：依然为单网格候选，没有独立后坐或轮组动画，背面生成细节与边缘不规则尚未修复；图形接合不代表机械拆件或十二混搭验收。Android待验。下一步先确认此样板观感，再统一全家族模板和修整模型，不逐件私设最终尺寸。
