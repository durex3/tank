# 080 炮塔与底盘统一尺寸

日期：2026-10-14。状态：实现、桌面检查与实际渲染复核通过；Android与真人观感待验收。

目标：修复用户指出炮塔/底盘大小不一致的问题，四炮塔统一宽高总长，三底盘统一宽高总长，造型可不同。所属presentation，不改领域、碰撞、属性、载重或存档。

测量证据：原轻履带1.65×0.847364×1.763323米，重履带2.13×0.760946×2.270380米；后者宽/长约多29%，使同一炮塔视觉偏小。原四炮塔高度0.457692—0.722698米、总长1.612255—2.179361米，未满足用户要求。

统一结果：炮塔1.32×0.68×1.90米；底盘1.65×0.847364×1.763323米。初轮试用原主战炮全外廓压低其他炮塔，实际渲染发现过扁，未采用；最终主战炮也纳入共同尺寸校准。美术契约见docs/art/080-部件统一尺寸契约.md。采用轴向表现缩放与偏移，因此部分原造型比例会随共同尺寸调整；不是仅放大之前三炮塔的百分比方案。

接口：最外层根identity与直接权威挂点不变，Geometry分支实例化保留原场景并独立校准。TankRecoil已有父变换逆矩阵适配，后坐仍使用世界米；TrackRig/车轮绑定不变。无架构例外。

变更文件：presentation/part_size_style.gd、content/presentation/part_size.tres；tools/normalize_part_sizes.gd；presentation/parts/unified_size_v1七场景与calibration.json；tank_part_catalog.gd七映射；tests/presentation/part_size_tests.gd接入tools/check.mjs；tools/capture_unified_icons.gd及assets/derived/unified-size-v1七张卡片；hangar_part_art_catalog.gd映射新卡片。规则同步AGENTS.md、architecture.md、code-style.md与080美术契约；开发计划和功能索引更新。
