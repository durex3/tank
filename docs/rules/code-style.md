- 089：新增命令字段同时更新验证及玩家/对手快照复制；turn_preference限定-1/0/1，仅消除180°路径歧义。WASD移动映射和鼠标世界瞄准保持独立，普通角度不套转向偏好。

- 086—088：可视出膛位置通过session注入，不能写回ProjectileState；双管交替与动作按成功事实去重。转速读content/rules/tank_steering.tres，body_yaw唯一所有者仍为TankMotor。轮组源顶点/法线/切线派生另存，卡片灯光与相机写独立PartCardRenderStyle，不改模型比例。

- 080起部件统一视觉尺寸写content/presentation/part_size.tres；离线工具读取固定原场景，校准场景另存，禁止累积缩放与逐件任意尺寸。静止外廓包含MeshInstance与MultiMesh；权威挂点独立，回归与实际渲染遵守080美术契约。

- 文件/目录/函数/变量snake_case，类PascalCase，常量UPPER_SNAKE_CASE，稳定ID使用StringName。资源ID不随显示名改变。
- GDScript用Tab缩进，UTF-8/LF；公开字段、参数、返回值显式类型。顺序：extends、class_name、文档、signal、enum/const、export、状态、生命周期、公开方法、私有方法。
- Node引用在_ready/@onready获取；物理只在固定tick执行。禁止在_process写权威战斗状态。订阅跟随会话生命周期。
- 调参写在Resource；运行时不可修改共享定义。公式只有一个实现，HUD展示解析结果。
- 函数聚焦一项职责，超过60行或脚本超过300行应评估拆分；生成数据/测试可说明例外。禁止通过拆文件却保留循环依赖规避分层。
- 输入拒绝NaN/Inf、非法ID、过期会话和重复请求。系统取消与正常松手分开，取消不能开火。
- 错误返回明确原因，不能用默认值吞掉资源缺失。日志标记类别；禁止输出秘密。
- 注释说明原因、单位和边界；功能名、状态、验收结果清晰准确。用户文字后续以翻译key管理。
- 测试关注规则边界与外部行为，不镜像实现。新增定义验证ID、引用、非负伤害、正冷却及弹丸预算。
- 美术先复用assets并检查provenance；生成图保存提示词、用途与来源。资产外观不改变碰撞与权威射口。
- 每功能写独立编号记录；完成意味着实现和对应自动验收通过，真机项目单独列待验收。

- 美术与机械动态遵守docs/art/068-坦克美术质感与动态表现规范.md；调参放表现Resource，派生网格保留重建工具/来源，实例动作和材质独立。视觉“已实现”必须有实际渲染与行为验收，不能以参考资源存在替代本项目完成证据。
