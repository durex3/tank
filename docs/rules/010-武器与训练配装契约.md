# 010武器与训练配装契约

主炮/散射炮松手单发，机关炮按住连续；输入只生成PlayerCommand，连续标志写只读WeaponDef。固定tick冷却统一由WeaponController裁决；机关炮松手不能补发单发请求。失焦/暂停/设备交接清除持有状态，显式重新按下才恢复。

攻击形状策略只输出弧度偏移；单发策略用于主炮/机关炮，散射策略生成包含两端的等间隔对称扇形（5颗，24度总角度）。所有弹丸先通过相同权威射口与车身至射口扫掠，再沿各自方向飞行。先检查整个弹组预算，空间不足整组拒绝，不创建任何命中或半组弹丸；一次攻击只发布一个weapon_fired事实。预算拒绝仍消耗本次冷却，防止每tick重试刷屏。

机库向app传稳定ID，由应用组装新MovementSession；仅开局配置，禁止比赛中更换绕过冷却。新的训练会话统一设置模型、属性、武器和输入模式。返回机库恢复本次选择，不写持久化存档。技能和被动本批不实现，不能宣称九种完整玩法完成。
