# 012-离线单局与结算契约

实现前冻结接口。原始标准为3v3、4分钟/20分、平分最多30秒加时；本批独立offline_duel规则仅2车，复用标准时间/比分，明确显示1v1规则验证，不能宣称3v3完成。

- MatchRules.validate验证正时长/比分/复活/保护/加时、每队人数和禁止友伤；开局复制规则，局内不修改内容Resource。
- MatchRuntime为battle内纯规则组件，开局冻结match_id与参赛ID→阵营。只接DamageResolver已提交的批量结果，按entity_id+life_index去重死亡；对手有效击杀加1，自毁/友军/训练靶/非参赛者不加分。所有死亡先计分，再统一判胜。
- 正常时间任一队达到目标，领先队胜；双方同tick达标且同分进入加时。正常时间到达仍同分进入加时，否则领先队胜。加时同tick有效得分后仍相同则继续，领先即胜；最多30秒仍同分判平。tick时限包含该tick已提交伤害。
- 计时只用模拟tick，暂停冻结。match_updated只在秒数/比分/阶段变化时发布；match_finished每局一次，结果副本不可反改内部统计。
- 结束阻止下一tick、输入、弹丸和复活推进，清输入并冻结表现；不能用暂停恢复结束的比赛。UI只显示比分/倒计时/击杀死亡伤害与结算，不裁决胜负。
- 训练仍无比分。Start timed duel创建全新会话而不把练靶历史带入比赛；Rematch同样重新组装，沿用配装/设备模式与返回目的地，清旧tick/HP/弹丸/统计/订阅。离开旧屏幕先stop再释放，旧输入不得作用到新会话。
- 本批不发金币/经验，不建立虚假奖励成功状态；无助攻分摊实现时不显示伪造助攻。
