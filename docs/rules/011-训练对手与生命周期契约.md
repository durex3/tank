# 011训练对手与生命周期契约

训练对手显式开启，默认练靶无敌对Bot。对手只在预设中央通道巡逻，不宣称具备全地图寻路；看不到玩家、超射程或玩家死亡时不请求开火。Bot输入层只接收位置、存活、视线等值，不引用battle节点；session获取物理视线并传给Bot，battle统一验证PlayerCommand与执行攻击。

玩家与Bot的TankActor共用DamageableState、ProjectileSystem、WeaponController、DamageResolver。发射前确定队伍，自己的伤害区与友军不受伤；双方先发射后同tick批量伤害，允许互相击毁。伤害只由DamageResolver写HP。生命周期模块负责死亡停止、180tick后安全点重建、life_index增加、60tick保护；找不到安全点继续等待，不强行重叠。

死亡/重建/暂停/控制器切换清输入，玩家重建更新epoch，旧命令不可跨生命；死亡禁止移动和射击。复活保护期间受到弹丸命中不扣血，不向外输出攻击；已发射的弹丸仍按原队伍飞行。所有倒计时在固定模拟tick内，暂停冻结双方及弹丸。训练不产生正式收益/胜负。

UI/模型只订阅事件显示HP、保护和死亡状态，炮口/命中/爆炸继续复用既有资源。对手采用现有独立部件场景和明确敌方标记，不额外复制战斗公式。
