# Tank presentation artwork

`cannon-hero-v1.png` is an original AI-generated transparent raster illustration,
created with the built-in image generation tool on 2026-10-11 for this project.
Direction: rounded white armor, gold muzzle, charcoal tracks, green optics.
User screenshots were visual references; no screenshot pixels or logos are shipped.

This image is a static lobby presentation asset. Runtime tanks remain separately
authored procedural 3D meshes in `scripts/visuals.gd`; this illustration does not
establish their rendering quality or constitute an imported 3D model.
