# Tank Arena


Godot 4.7.2、Compatibility、横屏、60Hz、XZ玩法平面的手机坦克项目。当前为离线原型：4炮塔×3底盘共12种基础配装，支持训练、普通对练及1v1计时规则验证；完整3v3与联机未完成。

## 当前范围

32项部件目录可浏览，4炮塔（主战炮、机炮、散射、泡泡）与3底盘（轻履带、重履带、侦察轮式）就绪，其余25项尚不可应用/试炼。支持显式等级成长、金币解锁/升级、载重限制、属性比较、草稿/撤销/应用和可恢复存档。首轮补给300金币，训练不发正式收益。

四炮塔普通攻击、大招及三底盘被动已执行；最新行为见开发交接和运行Resource。085已实现四种普攻独立轮廓/命中和大招阶段反馈；086补可视出膛衔接及双管交替；087补车身有限转向和侦察轮组圆度/转向；088重渲染立体部件卡片；089修复180°反向转弯路径，保留WASD方向移动与鼠标独立瞄准。

真实3D部件、炮管后坐、车轮/履带动态、统一尺寸及清洁哑光材质已接入。机库默认真实模型并可拖动旋转；未就绪部件显示不可旋转静态设计。模型基于proportion_v1，机炮/侦察映射feedback_v1；七张卡片使用model-reference-cards-v1参考图派生插画。

## 运行与操作

Godot打开project.godot，F5运行。首页进入训练或机库；试炼可保留预览草稿，应用才保存，返回主页丢弃草稿。WASD/方向键移动、鼠标瞄准；主炮/散射/泡泡松开鼠标或空格发射，机炮按住连射。触控左摇杆移动、右摇杆瞄准；Q或技能按钮放大招。训练补能不重置技能间隔。Esc/暂停按钮暂停，失焦后必须显式继续。

普通对练支持死亡、安全位置重建与保护期。1v1计时对局4分钟或20分结束，平分最多30秒加时；重开创建新会话，不发正式奖励。训练靶碰撞与耐久独立于视觉模型。桌面鼠标不替代Android多指。
